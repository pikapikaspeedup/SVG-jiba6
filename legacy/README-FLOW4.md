# INK FLOW 04 · 不知火舞「花焰」强化版

在你提供的 `INK-Flow-3-Source.zip` 上继续开发。保留八位角色、原有动作工坊与连段实验室，重点改进出招交接、输入缓冲、世界特效寿命，以及不知火舞的折扇、发辫、腰带和火焰轨迹。

## 打开与体验

直接打开 `dist/INK-Street-Fighter-6.html`，或先打开根目录的 `OPEN-ME.html`。这是完整创作版；`dist/INK-Street-Fighter-6-Player.html` 是不显示编辑入口的玩家版。两份成品都将脚本、动作、矢量画和场景内嵌在单个 HTML 中，运行不依赖外部素材、字体或服务器。

首页新增 **「查看动作演武」** 与 **「舞 · 14 HIT 实战连段」**。

**动作演武** 使用实际可编辑资产，不是预录动画。五个入口分别查看龙炎舞、飞翔龙炎阵、必杀忍蜂、阳炎之舞和炎舞仇樱；支持慢放、暂停、拖动到小数帧、反向查看和镜像。这里不生成伤害。要验证连招，进入实战连段。

**实战连段** 通过正常出招、资源与命中系统演示舞的 14 HIT 路线。连段页仍可切换全部八位角色、16 条路线和左右朝向。进入「节奏入门 · G」后，每按一次 G 只请求下一步，可选择 6F、3F、0F 缓冲；不按键不会自动代打。R 重置，空格暂停，暂停后可单步。

**动作工坊** 可继续编辑并「保存并实战」。新增特效选项包括扇柄/扇尖挂点、轨迹宽度、拖尾帧数、前后景层、花瓣、重力、阻尼和横向摆动。保存、招式 JSON、工程备份和导出 HTML 都保留这些字段。

图文操作见 [`docs/FLOW-GUIDE.html`](docs/FLOW-GUIDE.html)。

## 这次具体改了什么

### 动作与连招

换招时用短时惯性残差承接上一姿势与速度，在下一招第一有效帧之前回到原资产。交接角度取短弧，但一招内部的 360°/720° 转身仍保留完整旋转。世界位移仍由原战斗系统负责。

常规输入缓冲仍是 **9 个可行动模拟帧**，不再被命中定格、超级必杀冻结或慢动作跳过的模拟步消耗。缓冲成功后只执行一次，依旧检查能量、状态和取消条件。节奏训练的 **0/3/6F** 是实验室独立的提前请求窗口，不是第二条自动连招队列。

### 不知火舞专属动作表现

共更新 **44 份舞的资产**：18 份普通技、20 份必杀技、4 份超级必杀，以及待机和乱樱相关资产。没有重做或替换其他角色的全部动作。

折扇改为独立径向扇骨与纸面分片，开合不再只是纵向压扁图片；`fanGrip`、`fanTip` 与实际 SVG 武器坐标一致。发辫、腰带与绒球根据转身、旋转和发力节拍滞后回摆；装饰运动不参与判定，并可确定性反向采样。

龙炎舞走扇尖焰弧，飞翔龙炎阵走腿部升焰，必杀忍蜂走肘部冲刺轨迹；花蝶扇与空中动作也有对应的出扇和拖尾参数。补齐原本没有独立特效事件的 SA2、SA3、CA；SA3/CA 各使用 12 个编排事件，区分扇势火焰与收束花瓣。

### 特效系统

角色前后景轨迹与世界粒子分离。世界特效使用自己的可行动帧时钟，命中定格时不会比人物先消失；已发出的火星和世界拖尾在取消换招后继续自然消散。

轨迹按弧长重采样，四分之一帧缓存之间继续插值；反向拖动不依赖上一张画面。花瓣使用种子随机和解析位置，根节点旋转时保持已发射粒子的世界方向。容量满时，真实命中核心可以替换低优先级环境粒子。

固定上限：世界粒子 320、每个角色局部粒子 144、世界拖尾片段 64、每个角色根轨迹历史 40 条、每个局部挂点缓存 2048 项。所有这些只控制表现，不增加命中次数。

连段页「视觉强度」有 **完整演出 / 清爽 · 低闪动 / 关闭粒子与轨迹**。清爽模式降低粒子密度、关闭额外镜头震动和全屏命中闪光、抑制装饰摆动；系统开启减少动态效果时，演武默认暂停，仍可手动播放或拖动。

## 没有偷偷改变的内容

`game.js` 与原包逐字节一致。690 份既有招式、状态和投技的 `binding` 与 `boxes` 配置，以及 16 条路线定义，与原包对照一致。没有通过免费回能、扩大判定、延长受击硬直或脚本写伤害让演示成立。

姿势仍是共享骨骼的输入，因此视觉插值的变化可能影响空间采样；“规则配置未变”不等于宣称所有边界碰撞逐点完全相同。连段与机制需要实战回归，本包附带实际测试。

## 更新与保存

先保留旧目录，再将此包解压到新目录。新版浏览器工程命名空间为 `ink-flow-sf6-v4`，不会自动覆盖旧版 `v3` 的浏览器存储。

旧版有未导出的个人编辑时，先在旧版「资产中心」备份修改 JSON，再在新版显式导入。导入旧版舞的动作会覆盖对应新版资产的部分内容，建议先单独备份、比较后再决定保留哪一份。没有自动合并旧编辑与这次编舞。

浏览器禁止本地持久化时，可以继续内存编辑，但请及时导出 JSON、工程 ZIP 或游戏 HTML。玩家版隐藏编辑入口，不是防复制或权限隔离机制。

## 开发与复现

构建仅需 Python 3.10+ 标准库：

```sh
python tools/build_forge.py
```

测试需要 Node、`requirements-dev.txt` 中的 Python 依赖和 Chromium。已有浏览器时可通过 `INK_CHROMIUM` 指定可执行文件；例如 Windows PowerShell：

```powershell
$env:PYTHONUTF8 = "1"
$env:INK_CHROMIUM = "C:\Program Files\Google\Chrome\Application\chrome.exe"
python tools/check_flow.py
python tools/check_flow4.py
```

完整回归也可用 `python tools/check_flow4.py --with-original`。长时间检查是显式命令，不在每次快速测试中自动执行：

```sh
python tests/flow4/endurance.py --seconds 1200
python tools/check_flow4.py --report-only --require-soak
python tests/flow4/visual_sheet.py
python tools/prove_rebuild.py
python tools/check_flow.py --report-only
python tools/write_flow4_report.py
python tools/package_flow.py ..
python tools/check_source_zip.py ../INK-Flow-4-Mai-Source.zip
```

`--report-only` 只汇总已存在的测试证据，并不代表重新执行测试。`--require-soak` 要求当前 HTML 的 SHA-256 与已完成的 20 分钟报告相符。
