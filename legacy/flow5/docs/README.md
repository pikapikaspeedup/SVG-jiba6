# INK FLOW 05 · 动作图与特效运行时

在用户提供的 **INK-Flow-4-Mai-Source.zip** 上实施的下一轮引擎迭代。保留八位角色、690 份动作/状态资产、16 条连段路线、动作工坊和玩家版。此次重点不是增加几种装饰，而是更换动作与特效的运行路径。

## 先打开哪里

打开根目录 **OPEN-ME.html**，或直接打开 **dist/INK-Street-Fighter-6.html**。后者是完整创作版；**dist/INK-Street-Fighter-6-Player.html** 隐藏编辑入口，保留对战、演武与引擎检视。两份游戏均为脚本、SVG、场景、动作内嵌的独立 HTML，不依赖外部字体或素材。

首页进入 **「打开引擎检视」**：选择龙炎舞，将帧号拖到 22～28F，分别关闭分层动作、支撑脚约束与弹簧链。左右保持同一帧，右侧显示最终 SVG、扇尖偏移、三段发辫角度和末端角速度。左侧是当前资产的基础轨参考，**不是独立运行的旧版本**。

然后进入 **「舞 · 14 HIT 实战连段」** 检查真正的出招、取消、命中和资源消耗。连段实验室保留 16 条路线、左右朝向、示范与 G 键节奏练习；G 每按一次只请求下一步，长按不会自动代打。0F／3F／6F 是提前请求窗口，R 重置，空格暂停。

动作工坊的「动作」面板新增叠加权重、弹簧角频率、阻尼比、发辫/腰带强度；「特效」面板新增距离间距、每帧发射率、初始爆发数和速度继承。保存、JSON、工程备份和导出 HTML 均保留新参数。**新增分层轨道、接触窗口和寿命曲线的完整编排目前使用 JSON，不是可视化节点编辑器。**

## 本轮实际替换的运行路径

| 引擎部分 | 现在如何执行 |
| --- | --- |
| 游戏时钟 | 真正的 `game.js` 主循环调用 `INK.EngineClock`；60 Hz 固定模拟，独立渲染插值，小数帧重绘不推进战斗和发射器 |
| 动作采样 | `CompiledClip` 将关键帧预编译为类型化系数，二分定位，替代运行时重复解析；保留原曲线与整圈转身 |
| 动作图 | 基础轨与原交接 → 带权重/遮罩的叠加层 → 有界支撑脚约束 → 表现层交接 → IK → SVG |
| 附件运动 | 120 Hz 预采样的阻尼弹簧链；发辫、腰带有三段角度和速度，反向拖动可以重建 |
| 特效事件 | 实战模拟帧拥有 start/end/cancel 生命周期；发射器消费这套事件，渲染不重复触发 |
| 发射与拖尾 | 按挂点移动距离和时间率发射、继承速度；连续带状拖尾保留多点历史，取消后停止出生但已发效果继续衰减 |

**本轮 `game.js` 确实改动。** FLOW4 中由构建器注入的集成代码已落到正式源文件；构建器直接读取 `game.js`，不再以字符串替换方式修改战斗函数体。新增模块见 `src/ink/compiled-motion.js`、`engine-clock.js`、`motion-graph.js`、`secondary-dynamics.js`、`fx-timeline.js`、`fx-emitter.js`、`ribbon-geometry.js`。

原始未集成游戏源保存在 `legacy/game-flow3.js`；旧构建器保存在 `legacy/build-flow4.py`，仅用于审阅历史。当前完整实现仍复用原战斗规则，不是从零重写整套格斗游戏。

## 不知火舞本轮的接入范围

更新 **43 份**舞的记录：18 份普通技、20 份必杀、4 份超级必杀和待机。新增躯干反向跟随、折扇跟随层、部分站立动作的支撑脚窗口、弹簧参数，以及距离发射和寿命曲线。其他角色使用同一时钟、编译采样器和特效运行时，但没有假称全部重新编舞。

FLOW4 的 **690 份基础关键帧轨道、动作绑定和判定框配置均未改写**，16 条连段路线定义也保留。新表现层输出为 `visualPose`，不覆盖 `pose`，不反馈给伤害、根位移和攻击判定。关闭/开启动作图进行真实连段对照，结果见测试报告。没有通过免费回能、直接写伤害或扩大判定来凑连段。

## 保存和旧工程迁移

保留旧目录，解压到新目录。默认浏览器存储为 `ink-flow-sf6-v5`，玩家版为 `ink-flow-player-5`，不会自动覆盖 v4 存储。旧编辑先导出备份，再显式导入新版。

导入是一份完整招式覆盖另一份，不是语义合并。旧记录没有 `clip.meta.motion5` 时仍可运行，但覆盖的那一招不会自动获得本轮配置的分层/接触窗口；这用于保留用户原编辑，不能理解为新引擎失效。先备份新版，再比较后决定保留哪个版本。

浏览器禁止持久化时仍可内存编辑，关闭前导出 JSON、工程 ZIP 或可玩 HTML。玩家版是界面裁剪，不是权限或保密机制。

## 构建与验收

只重新构建：Python 3.10+，标准库，无需 npm 或服务器。

```sh
python tools/build_forge.py
```

运行当前版本完整快速检查：Node、Python 的 `requirements-dev.txt` 依赖和 Chromium。Windows PowerShell 可指定已安装浏览器路径：

```powershell
$env:PYTHONUTF8 = "1"
$env:INK_CHROMIUM = "C:\Program Files\Google\Chrome\Application\chrome.exe"
python tools/check_flow5.py
```

实际 20 分钟持续运行单独开启，避免快速检查覆盖长测证据：

```sh
python tests/flow5/endurance.py --seconds 1200
python tools/check_flow5.py --report-only --require-soak
python tools/package_flow5.py ..
python tools/verify_flow_package.py
```

`--report-only` **只核对已有证据，不重跑测试**。每份当前测试记录绑定游戏 HTML 的 SHA-256，不能用旧版本通过记录验收新构建。`--require-soak` 要求当前构建已有不少于 1,200 秒的通过记录。

当前入口是 `check_flow5.py`、`package_flow5.py`。旧 `check_flow.py`、`check_flow4.py`、`package_flow.py` 和旧 QA 仅作为历史材料，包含当时版本/源文件不变的断言，**不用于验收 FLOW5**。

## 证据与边界

本轮目标和验收项：**PLAN-FLOW5.md**。实际运行结果：**TEST-REPORT-FLOW5.md**。原始数据：**qa/flow5/**。接口与配置说明：**docs/FLOW5-ENGINE.md**。历史文档不是本轮测试结论。

支撑脚约束是有界 IK 目标修正，超出腿长、接触淡入/淡出或纠正上限时仍可能滑动，不会拉长骨骼强行锁脚。附件是简化角弹簧链，没有布料/身体碰撞。慢放和反向拖动重建表现，不是网络回滚。严重掉帧时固定时钟限制追赶工作并明确统计丢弃步数，不保证任意设备实时 60 帧。

本环境实际 `file://` 导航被浏览器管理员策略阻止；浏览器测试加载完整独立 HTML 字节，不等于已验证本机双击权限、原生文件夹授权或持久化授权。手机仅做视口/触摸模拟，不保证真机帧率。

项目仍为非官方 SVG 同人格斗演绎。保留原权利说明，无官方 3D 模型/动画移植，无网络对战、远程提交或部署。
