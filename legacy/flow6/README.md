# INK FLOW 06 · 连续骨架与动作引擎

本版在用户提供的 `INK-Flow-5-Engine-Source.zip` 上修复动作模板污染、转身求解、肘膝连续性和部件连接。不是给旧版额外叠一层粒子，也不是仅在预览窗口替换人物。正式 `game.js`、动作工坊、演武、实战、可导出 HTML 都使用同一套新骨架和曲面渲染器。

## 打开与直接比较

解压后打开 **OPEN-ME.html**，或直接打开 **dist/INK-Street-Fighter-6.html**。后者为创作版；**dist/INK-Street-Fighter-6-Player.html** 为隐藏编辑入口的玩家版。两份游戏均为独立 HTML，脚本、SVG、场景与动作资产全部内嵌，无需 npm、服务器、字体下载或素材联网请求。

首页先点 **「打开骨架与转身检视」**。默认关闭特效，可以查看完整 360° 转身、重脚、中脚、龙炎舞、花蝶扇和飞翔龙炎阵；支持 0.15×／0.35×／0.5×／1×、逐帧、拖动、骨架叠加、左右镜像。先看转身的肩肘与手腕，再看重脚约 22F、中脚约 16F，最后完整播放龙炎舞。

**`qa/flow6/v5-v6-motion-comparison.mp4`** 是实际运行两个版本各自的 SVG 渲染器得到的对照，不是用新版关闭一个开关代替旧版。冻结的原版 HTML 在 `legacy/flow5/baseline-v5.html`。同一镜头、同一动作时间、无特效；对比同时包含引擎变化和修复后的资产，不是隔离单个算法的性能实验。视频按动作时间采样为慢放，不是设备帧率测量。

首页 **「舞 · 14 HIT 实战连段」** 检查真实出招、命中和取消。16 条连段路线与 G 键节奏练习继续保留。原高级引擎检视也保留，但其中“基础轨参考”不是旧版；对照旧版请以上述双版本录像为准。

## 这次实际修复了什么

**动作数据生成器。** 原 `K()` 浅拷贝共享了手腕、脚踝坐标数组，生成器多次采样会修改模板本身。已改成独立向量所有权；恢复 133 份受污染的迁移动作中的 151 条坐标轨。舞的中脚／重脚收招手腕曾出现约 −742／−723 的横坐标，修复后回到约 67。修复工具不在每次构建或导入时自动运行，不会擅自覆盖用户手绘轨道。

**连续关节。** 目标轨道以 1/4 帧采样编译为展开的关节角度，限制突变后用固定骨长重建。先在未转身的源空间解算，再整体投影肩、肘、腕和胯、膝、踝，不再只移动肩／胯后重新猜一遍肘膝。手掌与折扇投影完整基底，而不是把接近零长的投影前臂重新归一化成一个跳转角。

**真实接缝。** 上臂与前臂、大腿与小腿各自使用贯通整条肢体的单一外轮廓；填充、光影和裁剪共用该曲面。腰胯补齐连接面，衣纹按固定源骨长度建立，护腕和绑腿不再受“首次打开哪一帧”影响。脚踝与鞋分开变换，显式脚掌 `0°` 不再被当成缺省值。

**实际取消。** 从上一招继承的是最终关节角度与角速度，不只是目标坐标。同时修复了取消目标采样的缺省值错误：下一招没有声明的转角不能借用上一招的转角。交接在下一招首个有效帧前结束。

**舞的动作。** 4 份龙炎舞重新组织源空间手脚与胸胯／头部转轴，不再一边手工翻目标、一边转身体。13 份动作中的 69 个“值在变化却使用 hold”的物理关键帧改为连续插值。保留有意不变化的 hold 和折扇状态切换。

**特效跟随。** 继承 v5 的事件生命周期、距离发射、拖尾和粒子预算；这次让发射器、扇柄、扇尖与实际新关节使用同一套挂点。没有靠新增强光掩盖接缝。

## 战斗与表现边界

8 位角色、690 份动作／状态记录和 16 条路线保留。690 份动作绑定与判定框**配置**经过逐份对照，没有改动伤害、取消资源、启动／持续／恢复时长来凑连段。表现层的新关节曲面求解不反馈给规则层；规则层保留原 IK 求解器。

但本轮确实修复了**基础坐标资产**。原规则中随基础骨骼定位的攻击／受击位置可以因此变化，不应把“判定配置未改”理解为“与 v5 每一帧碰撞坐标完全一致”。当前原有机制与路线通过结果见报告，未声称通过视觉改造证明任意玩家对战完全等价。

## 旧编辑与迁移

v6 默认存储为 `ink-flow-sf6-v6`，玩家版为 `ink-flow-player-6`，不自动覆盖 v5。先在旧版导出备份，保留原目录，再有选择地导入新版。

旧招式导入是整份覆盖，不做语义合并。旧文件可能保留被污染的坐标；导入后相应动作也可能重新出现旧问题。新版不会以“修复”为名悄悄重写用户自定义动作。建议先体验新版随附资产，再比较决定保留哪些个人修改。迁移工具的每项变更都有 `qa/flow6/*-repair-journal.json` 和 `mai-turn-journal.json` 留档。

用户保存、撤销／重做、JSON 工程备份、独立创作版／玩家版导出继续可用。浏览器不允许持久化时，关闭前应导出备份。玩家版只是界面裁剪，不是权限隔离或保密机制。

## 构建和复现检查

只构建需要 Python 3.10+ 标准库：

```sh
python tools/build_forge.py
```

测试需要 Node、Python 的 `requirements-dev.txt` 依赖和已安装的 Chromium／Chrome。Windows PowerShell 可指定浏览器路径：

```powershell
$env:PYTHONUTF8 = "1"
$env:INK_CHROMIUM = "C:\Program Files\Google\Chrome\Application\chrome.exe"
python tools/check_flow6.py
```

真实 20 分钟连续运行和原始版本对照可单独重做；对照录像另需 ffmpeg：

```sh
python tests/flow6/endurance.py --seconds 1200
python tools/check_flow6.py --report-only --require-soak
python tests/flow6/capture-comparison.py
```

`--report-only` 只核对当前 HTML 指纹与已有证据，不执行测试。持续运行默认只有 60 秒，必须显式传 `--seconds 1200` 才是 20 分钟。`check_flow5.py` 等历史入口不适合作为 v6 验收入口。

入口与调用路径见 **docs/FLOW6-ENGINE.md**；目标及状态见 **PLAN-FLOW6.md**；最终结果见 **TEST-REPORT-FLOW6.md** 与 **qa/flow6/validation.json**。`qa/flow4`、`qa/flow5` 和旧报告是历史材料，不代表本版通过。

## 明确保留的限制

这是连续骨架驱动的 **2.5D SVG**，不是完整 3D 蒙皮、人体碰撞或布料系统。侧面有透视缩短，正背面仍依赖二维美术；对战面向仍按游戏规则镜像，未加入跨越对手时的独立 180° 转身状态。不能把“关节不脱开”理解为全部姿势已达到专业手绘动画的艺术质量。

已测自然取消在交接点保持关节位置；普通结束回待机、落地、受击、抓投和任意极端用户编辑不能据此声称全部数学连续。支撑脚约束仍是有界修正，超出可达范围时可能滑动；不会无限拉长腿来强行锁脚。

本环境原生 `file://` 导航被管理员策略阻止。浏览器检查加载完整 HTML 字节，不等于验证了用户本机文件权限、文件夹授权与持久化授权。手机验证是视口及触摸模拟，不是真机帧率保证。持续运行是本环境的一次实测，不是任意设备 60 FPS 承诺。

项目仍为非官方 SVG 同人格斗娱乐作品，保留原版权说明，无官方 3D 模型移植、联网对战或远程部署。

## 打包与解压重建核对

```sh
python tools/package_flow6.py ..
python tools/verify_flow6_package.py ../INK-Flow-6-Continuity-Source.zip
```

打包器要求当前构建的快速检查和真实 20 分钟记录均通过，不能以旧报告替代。包内 `SHA256SUMS.json` 覆盖除清单自身外的所有文件；验证器在新的临时目录校验清单并重新构建，对照两份 HTML、导出模板和实际游戏脚本的字节。

`CHANGESET-FLOW6-ENGINE.patch` 可逐行审阅本轮引擎／界面／构建变更，已对原始 v5 对应源文件执行 `git apply --check`。这份审阅补丁不包含动作资产修复，不能单独当作完整升级包；完整修订以本源码目录和资产修复日志为准。
