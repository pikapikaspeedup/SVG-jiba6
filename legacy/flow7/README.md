# INK FLOW 07 · 节奏与连段引擎

本版基于用户交付的 **FLOW 06 连续骨架版**，将命中停顿、取消时钟、输入缓冲和动作交接接入实际战斗，并加入可编辑的有限连携规则。不是单纯加速播放已有连段，也不是靠无限资源、延长受击硬直来凑命中数。

## 先体验

解压后打开 **OPEN-ME.html**，或直接打开 **dist/INK-Street-Fighter-6.html**。文件名中的 `6` 保留原构建路径；页面内版本是 **FLOW 07 / 7.0.0**。玩家版是 `dist/INK-Street-Fighter-6-Player.html`。两者都是内嵌脚本、SVG、场景和动作资产的独立 HTML，不需要 npm、素材服务器或联网字体。

首页进入 **「自由连段与节奏」**。先播放默认的 **「不知火舞 / 忍步·仇樱收束」**：蹲中拳 → 中脚 → 重拳 → OD 必杀忍蜂 → SA3。它在角落、168 起手距离、2 格斗气／3 格超级能量下形成 **12 HIT / 3640 伤害**。再试 **「扇舞·重击衔接」**：中拳 → 重拳 → 轻龙炎舞，零起手能量，**3 HIT / 1776 伤害**。这些是本作品规则下的路线，不是官方招式帧表的复刻。

需要更从容的手感时，将顶部设为 **重心节奏 + 0.85× 舒缓 + 拓展连携**。默认仍为 1.00×；停顿风格和全局速度是独立设置，两位角色同时受速度影响，招式启动／持续／收招的动作帧数不变。训练的其他慢放工具若同时启用，会在全局速度上叠加，比较速度时应将其他慢放恢复为 1×。

**验证连段**使用真实出招、真实资源扣除和命中判定。**G 键跟练**每次只请求一步，支持 0F／3F／6F 提前窗口；长按 G 不会持续代打。手机宽度下可以点“发动当前一步”。实战输入缓冲的 3F／6F／9F／12F 与 G 键教学窗口是两个不同参数。

## 这次变化

**同一个时间口径。** 取消窗口、舞的追投／空中追击、派生和输入缓冲按可推进的动作帧计时。命中定格不再吃掉本来属于玩家的取消窗口。界面和真实执行共用 `decideMove`，会区分等待命中、定格、资源不足、取消窗口结束、空地限制、连携次数上限等原因；查询本身不扣资源。

**有限、多出口的连携。** 35 份普通技资产新增 `transitions` 元数据，8 位角色的部分轻攻击支持有限衔接，舞另有中拳／脚技接重击等出口。额外连携必须命中或接触确认，默认最多 2 次；编辑器允许 1–3 次上限和 0–20 动作帧窗口，不支持挥空取消。原有普通技接必杀、必杀接超级必杀等规则仍保留；额外规则是“新增出口”，不是重写或封禁已有出口。超级必杀和投技不能作为额外连携的起点。

**真实的时间连续性修复。** 命中停顿结束时，渲染不再从已经显示的动作帧退回前一帧做插值。普通地面动作自然收招时，也会接管最终的关节姿势与速度，再平滑交接到待机；舞的 OD 忍蜂反弹走正式状态生命周期。取消和自然收招的连续性都有实际关节采样，不能由此推出落地、受击、抓投或任意极端编辑也都连续。

**打击分拍而非堆光。** 轻／中／重击、超级必杀起手／中间击／终结击采用不同定格。新命中形状区分防御、拳击、踢击、扇切、上挑、终结击；接触核心、2F 后续切痕、3F 后碎屑共用冻结时钟。中间连击减少烟雾堆叠，终结击有独立收束。沿用有上限的粒子与拖尾池，支持清爽和关闭特效。

## 自己编排与保存

右侧选择角色和招式，添加、删除、上移／下移步骤；“命中”是上一招至少命中几次才能继续，“间隔”是从上一招开始计算的动作帧间隔。起手资源、距离、角落和朝向在“起手资源与距离”内设置。路线最多 48 步。

保存创建个人副本，不覆盖内置路线。可导出当前路线 JSON、整个路线库和本次真实运行记录。原 16 条路线逐项保留，新加舞的 6 条路线，共 22 条。路线只能证明在其指定起手资源、距离和朝向下是否成立，不保证换到中场、不同距离或任意木桩状态仍成立。

创作版展开“创作者 · 编辑有限连携规则”，编辑实际动作 JSON 的 `transitions`，不是只更改演示脚本。玩家版隐藏这个编辑入口，但保留路线编排、练习和节奏选择；它只是 UI 裁剪，不是安全隔离。

导出独立创作版或玩家版 HTML，会同时带上动作修改、路线库和节奏设置。重新打开导出的 HTML，再次导出，仍保留这些内容。工程／路线 JSON 的导入会校验后一次性提交，未知招式、越界窗口、重复规则等不会形成半导入状态。

## 节奏是否比官方更快

v6 已是固定 **60 Hz** 逻辑，没有发现“显示器刷新越快、逻辑就越快”的推进方式。这里的 60 Hz 是模拟步频，不是任何设备一定达到 60 FPS 的承诺。

但 60 Hz 不代表手感相同。v6 普通轻／中／重击定格为 **3／5／7 帧**，本版重心预设为 **7／9／12 帧**；超级必杀中间击反而更紧凑，避免每击都拖慢。旧“舞·14 HIT”从首次请求到最后要求命中，v6 与本版 v6 停顿预设都是 **262 个模拟步（4.367 秒的 1× 标尺）**，重心预设是 **270 步（4.500 秒）**。最后一击后的定格与收招不在这个统计口径内。

因此，重心预设改变的是强弱拍，不是所有招式统一变慢。需要整体更慢时用 0.85×。本轮没有同版本官方实机逐帧基准，不能断言比官方快多少，也不把某个预设标为“官方速度”。

## 构建与验证

构建只需 Python 3.10+ 标准库：

```sh
python tools/build_forge.py
```

测试需要 Node、`requirements-dev.txt` 中的 Python 包和已安装 Chromium／Chrome。Windows PowerShell 可指定：

```powershell
$env:PYTHONUTF8 = "1"
$env:INK_CHROMIUM = "C:\Program Files\Google\Chrome\Application\chrome.exe"
python tools/check_flow7.py
```

持续运行、受控对照视频及验收单独执行；视频还需 ffmpeg。不要在内存不足的机器上同时开多组浏览器任务：

```sh
python tests/flow7/endurance.py --seconds 1500
python tests/flow7/capture-playback.py
python tools/check_flow7.py --report-only --require-soak --require-playback
python tools/package_flow7.py ..
python tools/verify_flow7_package.py ../INK-Flow-7-Rhythm-Source.zip
```

`--report-only` 仅验证已有结果的指纹，不会补跑缺失或过期测试。默认 endurance 只有 60 秒；显式传入 1500 才是 25 分钟实时时长。`check_flow6.py` 等历史入口不是本版验收入口。`qa/flow4`、`qa/flow5`、`qa/flow6` 是历史证据；本轮证据在 **qa/flow7**。

完整说明见 **docs/FLOW7-ENGINE.md**、**TEST-REPORT-FLOW7.md**。`CHANGESET-FLOW7-ENGINE.patch` 对照真实 v6 源码，包含运行时代码、界面与本次连携资产，不能用它替代完整游戏包。`tests/fixtures/flow6-asset-signatures.json` 来自原始 v6 ZIP，审计确认所有 690 份动作的既有内容、轨道、判定配置均未改动；35 份只新增连携元数据。

## 迁移和边界

v7 使用独立存储 `ink-flow-sf6-v7`／`ink-flow-player-7`，不自动覆盖 v6。先备份旧工程，再有选择地导入。旧动作是整份覆盖，可能覆盖本版新增连携字段；系统不会偷偷向个人旧动作注入新规则。浏览器不允许存储时，关闭前务必导出。

本作品仍是非官方 **2.5D SVG**，不是完整 3D 人体、联网对战或专业动画素材重制。本轮没有重画全部角色，也没有解决任意转身、极端姿势、服装穿插或脚锁问题。已有 v6 骨架与连续曲面继续使用；本轮重点修复动作衔接的时序，并增加可玩、可编辑的连携。

本环境原生 `file://` 导航仍被管理员策略阻止；独立 HTML 检查使用完整字节加载，不等于测试了你本机的文件夹授权和持久化授权。手机是视口与触摸模拟，不是真机帧率保证。演示视频是受控 60 Hz 真实战斗采样、输出 30 FPS 的无声对照，不是性能录像。
