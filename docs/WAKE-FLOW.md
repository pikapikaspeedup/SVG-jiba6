# 倒地起身攻防

`INK.WakeFlow` 将倒地期间的延迟与起身末段的迎击接入公共动作请求。默认不输入仍按原倒地、起身时序恢复；原 Q 付费方向受身由 Aerial 保留。模块仅负责许可、参数与模拟状态，不从绘制修改判定。

## 选择与代价

- `WAKE_DELAY`：免费，在地面 down、剩余时间大于 2 帧且尚未方向受身时使用。当前 down 增加 18 帧，每次倒地限一次，不能连续按键无限延长。延迟不主动缩短或延长原有 invuln；down 的原有接触规则保持不变。
- 原方向受身：仍由 `Aerial.recover` 扣 1 格斗气并选择方向。已选择方向受身不能再延迟；延迟之后仍可主动付费方向受身，等于放弃未走完的延迟换取快速方向起身。
- `WAKE_STRIKE`：起身 rise 剩余 1–4 帧时支付 1.5 格斗气发动；更早的 rise 请求可进入原输入缓冲，窗口仍按正常缓冲寿命过期。8 帧启动、3 帧活动、26 帧恢复、600 伤害、10 帧防御硬直，命中击倒以夺回空间。取消关闭，防住或挥空可罚。

迎击不继承旧起身无敌或投无敌。仅启动前段提供一次打击护甲，沿用正式判定的护甲承伤规则（目前承受 30% 伤害）；到动作 t>=6 清除未消费护甲，活动和恢复阶段没有残留护甲。投技、护甲破坏攻击、多段与延迟攻击仍可针对它。推进预算 18 世界单位，在已有启动末 5 帧和活动 3 帧内每帧推进 2.25，受舞台及实体碰撞限制，不吸附目标。

## 集成合同

1. `state(f,next,G)` 在公共 `setState` 改写状态之前调用；仅进入新的 down 周期时初始化 `_inkWake`，进入 attack 不清空本周期选择。
2. `decision(f,id,G)` 在主流程对 down/rise 一概拒绝之前运行。返回 `wake-delay` 或 `wake-strike`，含费用及缓冲许可；其他 id 返回 null。主流程仍负责统一资源/疲劳/无限训练检查。
3. `start(f,id,G)` 只提交免费延迟。迎击走主流程原子支付、建攻击实体，并调用 `prepare(f,m,decision)`（Runtime.prepare 之后、capture 之前）和 `commit(f,decision,G)`（建攻击实体之后）。commit 清除旧无敌、投无敌、方向受身、push 与 vx，记录本周期费用；它本身不重复扣款。
4. `step(f,G)` 在攻击 t 已推进之后、接触判定之前调用，确保 t>=6 的护甲在当帧判定前消失。每个可行动步调用，冻结期间不调用或由内部冻结保护直接跳过。统计快照替换写入；pose/inspect 只读。
5. `pose(f,source)` 仅给延迟倒地轻微收身，继承 Articulation 元数据。主流程初始化/重置时清空 `_inkWake`。

CPU 必须走同一公共 requestMove，使用相同费用、时序、护甲和取消规则；模块不另设 CPU 快捷入口。`inspect(f,G)` 提供许可、规则及周期记录；`paid` 记录本周期已接受迎击的名义费用（无限训练实际不扣款）。

## 验证范围

`node tests/wake-flow/unit.cjs` 覆盖一次延迟、方向受身互斥、末段窗口与冻结、准备参数、护甲到期、清除继承保护、周期重置与采样不写状态。此为模块短单测，主流程公共扣款、真实碰撞、按钮与 CPU 行为需由集成后的正式构建检查，不据此宣称实战验收通过。

## 当前正式集成

倒地 F 延迟、起身 E 迎击，原 Q 方向受身保留。自由练习下方「倒地之后」提供真实扫腿练习及同输入按钮。迎击在 Runtime 中以本角色 sMP 动作作相位重映射，保留实际拳部几何，使用独立系统招式的时序与资源；并非播放一段与判定无关的演出。

CPU 防守根据自身资源与延迟观测选择延迟、迎击或原方向受身，进攻方每个倒地周期只选择一次压起身/停手，不逐帧重掷直到进攻。固定近距困难模式 16 个种子中防守选择为延迟 5、迎击 5、受身 6；进攻选择为压起身 12、停手 4。该样本不等于全难度或长期平衡。

`GroundContact` 从真实落地提交速度、横向惯性、倒地/投技/快落类型；雨地水纹、庭院尘土和天台碎屑共用有界 SVG 节点池。事件最多 8 条、可见 4 层，冻结与重复绘制不生成事件、不改变根位置。保留原粒子质量与稳定镜头。

当前短测：起身真实交锋 38 项、地面与按钮 10 项、原空中机制 17 项通过，CPU 32 个代表局通过；角色造型另有八角色动作短检及 96 组几何边界。汇总 `qa/wake-flow/checkpoint.json`。未执行新一轮耐久、实物设备、全部招式或长期平衡验收；持续目标仍然 active。
