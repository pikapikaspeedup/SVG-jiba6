# FLOW 08 · 动作响应与姿态回放合同

## 真实调用路径

`simulate()` 包装原有规则步 `simulateCore()`；只有真实 tick 前进才允许记录姿态。原有 60 Hz 规则仍独立运行。

可行动作步开始时 `Presentation.begin` 保存两个角色的前态并推进角色表现时钟；投射物的前位置／年龄则在 `updateFX` 之前保存。输入和移动、状态切换、碰撞与投射物更新沿原规则执行。`Presentation.finish` 记录实际运动通道差分，供下一次切换估计出站速度。结束后 `Replay.capture` 可选择记录完整的已解算姿态。

绘制时 `Presentation.view` 为当前对象创建只读用途的浅派生视图：插值 y、vy、walkT、landT、stateAge、jumpPre、表现时钟、攻击时间和状态时间。不同状态标识、攻击实例或方向不可强行插值。投技保持原有握持约束；命中、暂停及冻结出口按既有精确显示帧处理。

同一视图贯穿 `desiredPose → Runtime.visual → visualRig → Game.update → Renderer`，特别是附件求值也读视图，不能重新读整数帧实体。渲染可以更新 DOM 缓存，但不能改变规则时间、物理根、生命、资源、取消记录或输入队列。

## 三种姿态所有权

规则姿态用于碰撞和正式行动条件。视觉姿态加入动作图、合法取消桥、落地缓冲与状态桥。记录姿态再固化已经求出的源空间关节角，供检视恢复，而不是导入后重新猜测肘膝朝向。

`Articulation.attachSnapshot` 通过 WeakMap 为特定姿势携带源关节角；恢复时正向运动学使用该角度和录制时骨架长度，再经过既有统一 2.5D 投影。普通游戏路径不因回放功能变成读快照。原矩阵、蒙皮与战斗碰撞求解继续分离。

## 状态切换与落地

`StateTransitions.capture(f)` 求值当前真实姿态，并沿上一模拟步通道速度回看 0.25F，获得姿势差分、关节差分和附件结果；它不读取 `f.pose`。`Runtime.stateChange` 在正式状态改变前取源状态。派生的行走、跳跃、落地等 clip 变化由 `State.tick` 接管。

交接默认最长 2–8 个可行动作帧；受击／防御／眩晕的躯干通道立即切换，肢体与武器仍做短桥。常用落地桥 4F，倒地 6F，起身 7F。此处是表现长度，不是硬直长度。规则切换方向不会插值成 scale=0；双人投技不走单人状态桥。

落地事件保存实际入地速度、表现时间和是否倒地；速度上界 40，只供表现。普通着地身体压缩使用解析阻尼响应，最大 7 个局部坐标单位，22F 后不再生效；新攻击不叠加这段身体压缩。发辫／衣带逐段延迟响应并限幅；清爽模式和关闭弹簧时不施加新增附件冲量。倒地不会被当作普通脚落地压缩。

新攻击的出站附件取完整表现结果，随后清理旧落地事件，避免已承接的冲量又加第二遍。

## 场景特效

`SceneFeedback.ground` 使用既有有界世界池；关闭时返回“已处理”，不落回旧粒子分支。清爽模式保留低透明度接触圈，不发扬尘／碎屑。其物理落地与命中不依赖是否成功分配粒子。

`SceneFeedback.ghost` 获取 `visualPose/visualRig/Runtime.presentation`，将真实身体绘制到最多六个复用的 silhouette Renderer。过载丢弃装饰残影并计数，不扩大池、不阻塞规则。寿命按世界 VFX 时间算 15F；关闭或清爽模式立即隐藏既有残影。重置和资产切换清理其 DOM。旧 fallback 保留给关闭 INK 渲染器时的兼容路径，正常游戏不会使用旧分段 DOM 剪影。

`SceneFeedback.camera` 对世界时间采样有限幅度的确定性位移；暂停和命中冻结期间返回相同偏移。系统减弱动态、清爽或关闭特效时返回零。它不是摄像机实体碰撞系统。投射物本体仍可见，其位置和可旋转扇面按同一 alpha 绘制；关闭装饰特效不隐藏攻击实体。

世界粒子 320、拖尾 64、每角色局部粒子 144、残影渲染器 6；状态事件 160，回放事件 240，回放帧 600。实际长期观测见持续运行报告。

## 姿态回放 API

`INK.Replay.begin(title)` 显式开启；`stop()` 停止但保留数据；`export()` 返回独立 JSON 对象；`parse(text)` 按 8 MB、schema 和有限数值约束验证；`load(data)` 先验证再替换，失败不清掉旧记录；`sample(index)` 返回只读用途快照，允许小数帧；`clear()` 清空。

JSON 顶层为 `version=1`、`kind=ink-pose-replay`、`hz=60`、title、engine、characters、frames、events。每帧包含 tick、action、frozen 与两个 actor；actor 保存人物身份、位置、方向、尺度、状态／招式时间、完整基础姿态通道、四肢两段关节角、附件姿态和记录时生命／资源／连击。characters 内嵌模型与骨架。事件类型仅 state、land、facing、contact。

整数采样精确恢复记录的解算关节。小数帧仅在同一人物、同一方向内插值；角度走最短弧，方向跳变离散显示，状态标签采用前一快照。导入时不允许同一 actor 槽位中途变成人物 B，不接受脚本、SVG、URL、未知顶层字段、原型污染键、非有限值、缺少的基本通道或倒序时间。

回放帧从模拟步骤记录，包括 hitstop，不依赖当时显示器抽了多少次样。它不是输入回放，也不是全世界回滚；不保存粒子、声音、碰撞框或 AI 内部状态。不能把导入的 HP 数值写回对战。

## UI 与持久化

`INKResponseLab.open/close/run/load/seek/paint/record` 为界面 API。run 只允许 jump、walk、knockdown、combo 四个检查场景，通过真实训练步骤生成记录。combo 运行当前自由连段草稿，并允许按真实返回报错，不补血、改伤害或伪造命中。

回放打开时暂停原战斗。关闭时仅在战斗对象与屏幕仍是原对象时恢复先前状态；改成新的训练场景后保持暂停。Esc 与关闭按钮走相同显式恢复路径。录制按钮是开始／停止查看，不是默认永远录制。

三项布尔设置 `interpolate/stateBlends/landingResponse` 原子验证；独立 HTML 的 portable snapshot 保存它们，浏览器可用时另存 `${store.id}/response8`。已有回放不因开关重算。

## 尚未覆盖的质量目标

脚接触仍是有界约束，不是全身动力学或永久锁脚；严格的关节速度连续和极端姿态自然度没有普遍证明。规则换边仍镜像，双人握持不重写。投射物判定起点保留原战斗求解，未来可独立增强视觉发射挂点到世界弹体的短程交接。没有全布料自碰撞、真实 3D 遮挡或官方动作／节奏标定。
