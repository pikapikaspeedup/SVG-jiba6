# 共享招式空间

第十五轮已将八角色的 sMP、sHP、cMK 共 24 招接入共同的动作与接触模型，拳路、扫腿、身体前送和收势暴露直接参与距离经营。攻击端与身体代理由同一固定骨长空间模型生成。

## 角色与招式

| 角色 | 出手设计 | 距离取舍 |
| --- | --- | --- |
| 隆 | 中拳直送，重拳更大胸肩前送 | 更远的重拳也暴露更多肩臂 |
| 肯 | 中拳短上弧，重拳上蓄后斜压 | 路线的中途高度不同 |
| 春丽 | 掌击、接近伸直的长低扫 | 长扫保留较长原收招时间 |
| 嘉米 | 深度方向收肘、紧凑直刺 | 窄路线与快速回护 |
| 卢克 | 肩胸压入、较少追求极限伸臂 | 前压身体可被截击 |
| 蛛俐 | 斜挑与斜压，低扫绕共同深度轴 | 中段最远，扫过的腿部空间变化 |
| 舞 | 短腕路配合扇面开合与转角 | 实际扇缘决定远端空间 |
| 八神 | 低护、前倾下沉、斜下爪 | 低线压迫伴随躯干暴露 |

`strike-model-data.js` 保存 24 招准备、活动起点/中点/末端、回收途经与退出节点。攻击端采用伸展率、上下角、深度角；角色原始骨长不变。普通技的时序、伤害、费用和合法取消规则不变；空间范围、身体暴露和依据接触位置计算的推力质量属于本轮明确调整。

## 同一个身体

`StrikeModel` 用固定三维两骨链求解四肢，再正交投影。局部骨盆位移与胸肩倾转带动蒙皮、头部和 hurt 参照，不修改战斗根位置。`StrikeModelFrame`、`StrikeCollider`、手脚附件、扇面和既有挥击轨迹读取共同结果。普通旧招仍使用兼容路径。

新模型拥有整段准备、活动和恢复，绕过旧 StrikeScore、StrikeContact、通用关节桥及额外脚约束。头部可读材质保留共同头中心。支持招的几何不由 Kinetic、MotionGraph、VFX 或 Runtime 显示开关决定；原本误绑 Kinetic 的推力、实际命中冻结和其他战斗规则已拆开。

规则入口来自成功接招前的旧原生实例或 `RulePose` 的模拟脚步与转向快照。旧兼容动作采用规则姿态拟合，不读取上一张绘制结果。旧招的人工伸展可能超过固定骨长，因此不承诺极端旧招接入时所有关节完全连续，也不保留拉骨来掩盖误差。

## 支撑与结果

`StrikeSupport` 只保存有限的入口计划，继续已有落脚，不建立另一套循环步态。站脚保持世界锚；cMK 的前腿由攻击拥有。共同下沉最多 12 个局部单位，仍不可达时只在模拟边界安排有限速度纠正步；不推根、不拉腿。新招取消继续支撑脚的旧摆步，原攻击腿从实际位置落回。自然回到 idle 同时交接脚锚与转向所有权，避免旧转身计划再次抬脚。显式瞬移平移并重基脚计划时钟，断开接触历史。

实际已结算的 hit、block、parry、armor、cleanMiss 形成有限收势方案；unknown 中性。变体在活动结束后以零位置/速度残差进入，伸展率偏移不超过 .035、方向角不超过 6 度、前倾不超过 2 度，不改恢复帧数。未确认命中不等于确证落空。

## 接触近似与边界

身体使用 20 个规范代理盒：头、胸腹髋、四肢每骨两段。拳脚使用末端代理与远端 72% 的两段；舞另有七个扇区，边界包含真实圆弧极值。躯干预变形与蒙皮权重和 Renderer 共用 `BodyProxy`。ID 用于时间配对，part 保留身体语义。

每个行动步采用八个几何子区间，区间内按 AABB 边线性插值扫掠。出生活动点只做离散检测；最后活动区间封口后才可能发布 cleanMiss。双方候选先共同采集，再按原规则提交；TOI 不新增先到者取消对方攻击的规则。

这是有空角误差的分部 AABB 近似，不是 SVG 像素级碰撞、三维物理或任意曲线精确 CCD。衣摆、头发和扇纸不会自动增加持有者受击体积。

## 创作与距离查询

实例仅在内置 model/rig/move 来源签名匹配时启用，并在接受动作时锁定版本。编辑同 ID 动作、骨架或自定义盒后，新实例整体回到兼容路径，不覆盖用户创作。正常运行期间实例使用已绑定的原始模型快照；编辑器提交事务时显式中止当前原生攻击并断开接触 epoch，然后才重建显示与规则入口，避免半招混用新旧身体。

`DuelReach` 以同一八分帧网格估计支持招的空间，余势只计入已取得的真实预算。AI 仍使用延迟公开观察；可达估计不保证对手未来不移动。付费连携既有空间门槛和训练摆位改读模型，普通合法取消没有新增必中门槛。

当前验证以少量真实交锋、所有角色姿态审看及相关纯几何检查为主；阶段证据绑定具体构建，不沿用旧哈希作新版本结论。未新增长回放、耐久或性能结论。
