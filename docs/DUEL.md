# DUEL · 完整格斗整合

第十轮将前九轮能力接进对手行为和玩家操作衔接。目标是能直接打一局有来回的格斗，而非继续扩展重演工具。

## 实战变化

- 移动意图使用与攻击缓冲相同的可行动作时钟。短按跳跃或双击冲刺可跨过最后几帧落地/收招；超过缓冲窗口就过期，不能跳过硬直。输入保留方向，暂停和新局清除。攻击请求优先于待执行的移动意图。
- CPU 读取原有延迟观察（挑战 9F、标准 15F、入门 23F），结合自己的资源决定行动，不读取对手尚未发生的输入。CPU 主动选择跳入，执行短跳、空中修正或快落；快落仍承担至少 11F 落地恢复，不能用 AI 绕过。
- 标准/挑战 CPU 在实际倒地后可能花费 1 格斗气受身：角落朝场内，其他位置远离观察到的对手。保留末段受击窗口；不是免费无敌脱身。
- CPU 有机会用真正的 OD 投射物争夺对波，支付原招式资源；观察到自己存活的波位于前方时跟进压制。概率、资源及反应时间均可导致它放弃此选项。
- 既有命中确认 AI 接续角色连携。八角色继续使用自身的必杀技、派生与超级技，未统一成同一种招式模板。

## 游玩

首页「开始格斗」直接进入 CPU 对战。战斗页可选择双方角色、难度和辅助/经典操作，也可切换本地双人或自由练习。「练习与引擎设置」默认收在画面下方，进入练习时展开，保留全部连携、空战、对波、场景与打击反馈控制。

`INK.DuelControl.settings.enabled` 和 `INK.DuelBrain.settings.enabled` 可分别禁用本轮移动缓冲和新增 CPU 决策；总开关仍为 KINETIC。引擎 API/存储版本保留 v9，707 份原始动作、模型、骨架与路线文件未改。

## 交付证据

`qa/duel/playable.json`：15 项直接检查，包含实际扫腿后的 CPU 付费受身、真实 OD 对波与存活波跟进、八角色各 1100 步实战、输入时钟和入口交互。

最终构建同时通过 KINETIC、FLOW CHAIN、AIR FLOW、MATERIAL FLOW、PROJECTILE FLOW、STAGE LIGHT、STRIKE FEEL、SUPER DIRECTOR 的全部可玩检查；第一轮擦身/接触回归保存在 `qa/duel/spacing/`。最终跨轮审计见 `qa/duel/completion.json`，报告均绑定同一 HTML SHA-256。未扩展或执行大型重演门禁。

`qa/duel/frame-cost.json`：所有升级开启，八角色分别顺序采样 480 步，前 120 步预热。同步模拟 + SVG DOM 更新 + 特效 CPU 平均约 0.83–1.01ms，P95 约 1.5–2.0ms；没有关闭特效、跳过骨架帧或暗中改速。这是本机短时 CPU 开销，未测 GPU 实际显示帧率、实物手机/手柄、音响主观听感或长时耐久，也不能据此宣称竞技平衡完成。

本轮由 Codex 完成设计和实现，未使用额外 Pro 咨询。

## 持续第十二轮：地面交锋升级

新增 `ExchangeFacts → DuelPerception → DuelReach/DuelWindow → ExchangeDuel`：接触结算后发布事实，双方 CPU 读取同批延迟观察，按真实稀疏活动几何选择短计划，再统一提交。探步、有限回撤和观察周期后选择再压迫或追击，Clinch 在近身接管。各模块 `settings.enabled` 可用于开发对照；事实与观察不改变伤害或几何规则。

事件只保留有限记录；学习采用递增序号水位，初始先验 0.5、独立证据更新 0.08、策略偏置上限 ±0.15。冻结只成熟反应等待，不推进动作。时间敏感请求为 tap、无 carry、无延后缓冲；预先蓄势通过真实输入。`RecoveryMotion` 仅对确证 cleanMiss 使用挥空收势。

本节对应 `qa/duel-exchange/checkpoint.json`，上方十轮性能与多角色报告仍属于历史构建。此次只做针对性单测、实际短对局和生产源码门禁；单击地面普通技以外不宣称完整落空证明，玩家输入时序未整体迁移，几何报价也不保证未来接触。


### 24 招独立动作谱

八角色站立中拳、站立重拳与蹲中脚采用独立视觉谱：准备剪影、护架、独立回拳/收腿和真实结果回收；活动链仍严格服从原战斗几何。固定源骨长与兼容伸展分开，手脚/舞扇与真实攻击链同源，左向过渡和受击接管保留附件连续。普通招式以外及特殊实例继续原路径。证据与边界见 `qa/strike-score/checkpoint.json`；没有改变原始伤害、时序、取消或资源规则。

## 持续第十四轮：挥击与接触表达

最终身体截面驱动世界挥击带，八种材质遵循真实路径；格挡近面裁剪、多段分拍、互击封口与小瞬移断段。一次接触共用 ImpactScore，身体、声音、冲击和局部光同步；普通接触收束主形状与光范围。原战斗时序、伤害、资源、推力保持，707 原资产不改。最终定向检查与声音声部证据见 `qa/impact-score/checkpoint.json`，具体边界见持续账本。
