# 八角色身体语言与统一接触

本轮将落地支撑、发力、方向性受击与接触音色推广到八角色。核心是同一真实战斗结果具有可辨认的身体表达；不改变攻击启动/活动帧、伤害、命中框或资产。

| 角色 | 身体语言 |
| --- | --- |
| 隆 | 根部稳定，肩胯蓄力与较重的制动承重 |
| 肯 | 出拳由后撑转前撑，身体追身，后手随发力回收 |
| 春丽 | 不对称换撑节拍，腿击时骨盆与胸部反向平衡 |
| 嘉米 | 转向时肩胯螺旋，轻快制动与较大的受击侧转 |
| 卢克 | 紧凑拳击支撑，护下巴与高后手，短肩转移重心 |
| 蛛俐 | 站姿抬起前腿不强制踩地，踢击时单脚承重与反向平衡 |
| 不知火舞 | 侧身扇舞、后手弧线与胸胯错转，保留攻击扇轨迹 |
| 八神 | 更低的站姿与低后爪，肩胯形成鞭打式反向发力 |

`BodySupport.step` 在模拟步保存有界踝部近似锚点与承重状态；`pose` 只读并表达躯干，最终 `constrainFeet` 只约束承重腿，保留已解算手臂与骨长。踢击前腿和受击退步腿卸载。第二阶段的 YIELD/ESCAPE 按真实根部移动交换退步脚，不从表现层移动战斗根。空中、捕获和特殊动作保留既有动作轨迹。

`ContactResponse.describe` 接收共同接触快照，输出冻结的角色风格、材质、接触部位、伤害部位、等级、多段及终结标记。`normalGeom` 是实际相交战斗盒的轴向法线（不是 SVG 曲面法线）；`responseDir` 是战斗推退方向。特效、音效与身体吸收共用该描述，避免独立猜测位置。

只有明确覆盖的地面单段、非击倒、非升空普通技能有 `affectsPush:true`。特殊技、投技、空中、多段、波、防御招架、装甲、捕获和不连续根位移仍能产生表现描述，但 `affectsPush:false`，`apply` 必须显式通过该字段才允许缩放既有推退。原有伤害、硬直、投技路径和空中运动保持战斗层所有权。推退倍率仍限制在命中 0.82–1.22、防御 0.86–1.16；实际差距有限，不能宣传为新的大型空间物理系统。

八角色共 80 个普通技使用显式 `{dNear,dFar}` 根距带，不读取 AI 的 `m.range`。校准来自生产活动帧命中盒与站立中立受击盒的垂直重叠采样，见 `qa/eight-fighters/geometry-calibration.json`。这只是已确认命中的质量归一化，不是扩大命中范围，也不是对所有姿态的命中保证。

音色保留防御、招架、投技识别以及既有声部上限。角色命中以低频根劲、追身热感、丝带腿击、风切、拳击低冲击、尖锐踢击、扇面高频和低沉爪击区分；多段避免重复添加终结层。

短检验：

```sh
node --test tests/eight-fighters/contracts.test.js
INK_CHROMIUM=/path/to/Chromium python tests/eight-fighters/playable.py
```

生产短测覆盖八角色真实命中、击倒表现、伤害/硬直保持、有限推退、发力姿态、制动、渲染只读及蛛俐抬腿支撑，输出成品哈希与截图。不是完整耐久或所有特殊技连段验收。

统一画面构图使用每名受击角色最新两层接触，较旧层减弱；舞台局部照明读取同一筛选结果。八种接触核心形状和音色保留角色身份，多段中间击降低强调，终结击恢复强调。原粒子质量和稳定镜头保留；这是一项可读性规则，不是降低采样率的性能优化。

`tests/eight-fighters/presentation.py` 通过普通、特殊、波、多段、投技的真实接触检查共用描述符，并比较特殊类型开关前后伤害、推力与运动轨迹。`qa/eight-fighters/completion.json` 汇总本轮及相关回归，旧报告只代表各自历史构建。
