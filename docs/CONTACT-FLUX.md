# 真实接触改变攻击流形

ContactFlux 把真实命中、防御、招架和霸体接触转换为冻结的视觉描述。它不扩大判定，不改变伤害、推力或攻击骨架。挥空不会产生接触快照。

## 提交与读取

`commit(source, config)` 只在正式接触提交时调用。config 包含真实事件 id、point、incoming、responseDir、result、born、character、category、strength、multi、last、part。born 默认读取 VFX.time；点和方向数组均复制冻结。方向归一化，强度限制 1–3。返回含唯一递增 serial 与 life=duration=12 的冻结快照。

真实 sourceAttack 作为 WeakMap 键，各源最多 8 份快照；相同源相同 id 返回原快照，不重复生成 serial。飞行道具可用 null 源，独立截面仍存在，并有最多 8 条近期去重记录。`read(source,time)` 只返回该源在当前时间最近有效的一份，不能把飞行道具接触错误关联到人物旧攻击。`clear()` 在场景重置时清全部历史与计数，须同时清现有 RibbonPool。

## 坐标和连续形状

`local(contact,pointFn)` 映射接触点及两个单位向量端点，产生局部方向和尺寸比例。人物拖尾必须先转到人物局部；世界拖尾直接使用原快照。时间始终来自 VFX.time，不能混用动作 clip 时间。

`deform(points,contact,time)` 返回新数组。普通技在接触点 64 单位内、其他攻击在 90 单位内施加平滑衰减；每点位移最多 24 单位，局部转换后按比例缩放。远端原点不变，不把整条攻击带吸附到接触点。

- 命中：沿来向短暂贯出。
- 防御：压缩接触面轴向，横向展开。
- 招架：沿响应方向选择侧向偏折；方向共线时固定侧偏，不使用随机数。
- 霸体：削短接触面后的流线，保留较短截断感。

影响随 12 个 VFX 时间单位平方衰减；冻结时同一时间得到相同结果。原 points、快照与模拟均不被渲染修改。

## 唯一接触截面

`section(contact,time,style)` 返回最多 3 层 d/fill/stroke/width/opacity。普通技只给一条短线；特殊技按气劲、火流、丝带、切风、脉冲、涡流、扇流、爪焰区分曲线。它不创建 DOM、节点池或粒子。

MaterialFlow 只负责连续带变形；独立截面由既有 RibbonPool 的 stamp 单次承载，避免人物流形和世界接触重复叠加同一截面。style 可指定 color/core/mode 保留原材质配色。

## 验证边界

`node tests/contact-flux/unit.cjs` 检查冻结快照、去重与 8 条上限、时间失效、坐标镜像缩放、远端不动、最大位移、纯采样以及八材质层数。它不替代正式接触事件与拖尾关联后的有限实战检查。

## 正式接入与阶段证据

共同碰撞批次在双方受击前记录攻击链来向，后处理的互击方不会借用已经受击的姿态。真实 sourceAttack 串联人物附体拖尾、世界拖尾和速度轨迹；飞行道具使用独立截面，事件 id 包含具体 projectileID，避免同帧多波混淆。角色局部坐标明确从世界接触变换，接触年龄始终用世界特效钟。

多段中间击使用两层与 70% 尺寸，末击恢复三层；普通技与减弱动态模式保持一层。既有十字/光圈/核心与长射线收敛，保留身体可读性。截面沿用 64 槽池，满池优先替换老尾迹，最后替换最老截面，保证新接触可见；不扩大容量或降低动作采样。

7 项真实接触/规则、32 组普通技结果与 2 组特殊技轨迹、4 项互击/减弱动态检查通过。16 组实际特殊技接触同步 CPU 样本平均约 1.23–1.71 ms，包含命中定格画面，不能解释成真实显示帧率。证据绑定 `qa/contact-flux/checkpoint.json`。原始 707 资产未改，本轮未咨询 Pro。
