
## 双人投技身体层

`ThrowBody.phase(action)` 使用原投技 t/release/duration，区分抓握、承重、转轴和释放。`pose(f,source)` 以既有姿态为基底，添加胸髋、头、肘导向、视觉下肢承重路径与手型，不更改抓取规则、伤害、根位置或被投者轨迹。隆的髋轴、肯的前压、春丽的反向胸髋、嘉米的螺旋、卢克的肩扛、蛛俐的侧轴、舞的扇舞转身和八神的低爪分别有独立路径。背投额外分配髋胸反向转轴，不把整个人简单镜像；空投使用躯干收紧而不增加地面下沉。

`constrain(f,source,context)` 仅约束抓取者、仅在释放之前生效。context 必须包含 source 的最终 `rig`、目标最终肩胸插座生成的世界 `anchors.front/rear`、`toWorld` 与 `toLocal`，以及相同解算使用的 character profile。转换函数的局部空间是 **projected sockets 空间**：toLocal 只逆去 Rig.world 的根变换。模块通过 projector × bodyMatrix 的阻尼最小二乘逆处理近侧轮廓，不再使用 inverseTarget 在近奇异投影下保持原 x 的分支。完整抓握不设原 48 单位人为残差；最终仍由原骨长 IK 限制，不延长手臂、不移动目标。

Runtime 在所有状态桥与脚约束之后调用 constrain。模块复制输入姿态并继承元数据，从最终 rig.anatomy.source 提取四肢角，仅重解双臂，最后 attachSnapshot 完整四肢角。新姿态身份避免旧 visualRig 缓存复用，既有腿部约束不被丢弃。目标先以 skipThrowConstraint 的完整视觉采样得到最终骨架，禁止双方递归调用完整约束；当前投技两人使用同一模拟采样时刻。

抓握在前 4 帧平滑建立，释放前三帧解除，release 当帧完全不再约束被投者。拆投由主模拟写 `_inkThrowTech={actorBirth,duration:8,dir}`，pose 只在 idle/recovery 中采样短暂拨手，不能覆盖之后的新攻击。

`tests/throw-body/unit.cjs` 检查八角色路径、分相、前后投与空投区别、左右朝向、采样纯度及拆投权限；不以数学检查代替最终双人抓握位置的正式构建验证。

八角色第二版轮廓进一步区分：髋投沉髋并后脚转轴，肯延伸后支撑腿向前压，春丽明显抬收前腿，嘉米拧身收腿，卢克双膝蓄压肩载，蛛俐侧提膝与反转髋胸，舞后腿收拢形成旋转线，八神宽低支撑下压。膝踝偏移仅属视觉，在固定模拟轨迹与原骨长下解算；两只抓握腕目标仍不由pose移动，最后constrain才贴合目标插座。actual腕位置读取Rig.sockets(source,rig)，与投影和关节元数据一致。以上较大轮廓仍需正式构建截图确认，不以数学差异冒充画面验收。

### 可达抓点选择

Runtime还提供regions：目标肩—上臂、肩—胸、胸—上腹部的真实世界线段。完整三区域使用每段固定9次采样、连续身体路径弧长soft-min；不足三区域的兼容输入保留8轮局部细化。模块计算每个候选经过原骨长IK与真实投影后的手端世界误差，选择实际可达抓点；误差主项之外，对原collar锚加入弱偏好正则，减少等价可达点之间无意义跳抓。近奇异逆保持有限，不以放大手臂补偿。进入和退出仍按同一个4帧/3帧包络。该方法是有界视觉约束，不是完整双人体积碰撞或物理解算。

诊断通过ThrowBody.inspect(finalPose)的WeakMap返回所选anchor、正算actual、error、segment、t；不写fighter、不依赖上一绘制帧。正式检查还需用最终Runtime.visualRig读取手端对照anchor，不能只相信内部误差。

### 独立抓握臂投影平面

抓握者双臂相对胸部投影角使用 `clamp(-bodyYaw × .78, -155, 155) × grip`。这是2.5D臂平面的可视化自由度，不是放宽肘关节或宣称人体力学准确。Anatomy保持原投影肩位置与骨长；大转身时手臂仍能朝向被投者，不被迫与胸部一起变成近零宽度的侧影。释放前三帧随grip恢复原投影平面并解除抓握。

最终针对性采样（构建含 .78 / ±155 臂平面）在八角色前、背投 t14 的 32 只手中，最终 visualRig 手端对实际所选身体锚误差均小于 0.01 世界单位。嘉米、蛛俐 t4–23 完整抓握区间最大误差小于 0.005，原近侧平面导致的巨大跳手已消除。八神该区间仍有最大约 27.57 单位的晚段前手可达残差；逐帧沿身体抓点滑动最大 9.28，低于早期离散选点造成的跳变，但不能宣称所有角色全时段精确贴合。报告保留最终骨架位置、选锚、原未约束手位移与身体抓点滑动，明确这项限制。

实际投技 CPU 样本独立顺序运行：八角色前/后投，完整投技预热一次后采样抓握帧 4–22；同步模拟、SVG 与 VFX DOM 均值 1.10–1.32 ms，p95 1.3–2.6 ms，见 `qa/throw-body/frame-cost.json`，不代表 GPU/显示帧率。
