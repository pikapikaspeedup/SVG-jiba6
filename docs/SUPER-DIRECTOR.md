# SUPER DIRECTOR：真实交锋驱动的超级技演出

第九轮将超级技的发动提示、连续接触、终结和收势纳入同一演出控制器。默认开启，“体验格斗升级”提供贴近练习和 SA1/2/3 按钮，仍消耗实际超级能量。

## 演出阶段

- 发动：显示紧凑的角色徽记和招式名，背景柔和收暗，保留双方站位。
- 交锋/飞行压制：跟随实际攻击实例或离身投射物，分别累计命中、防御和招架。
- 终结：只有实际末击命中才出现角色材质对应的结束线条；被挡住或打空不伪造终结。
- 收势、落空、被中断、强化启动：显示对应结果，随后退出。

支持双方各一条当前超级技演出。离身波通过原攻击实例关联，避免把上一发同名超级波的接触错误计到新招式。连击数字和血条保留；标题避开两侧连击区，并移除重复的发动通知。

## 构图约束

使用渐变背景聚焦和真实接触点附近的方向线，不移动相机或角色，不修改判定、招式帧数和超级技伤害。新模式大幅降低发动白闪；减少动态效果时隐藏终结速度线并减弱背景收暗。

演出状态在模拟边界维护，显示只读取阶段。标题退出使用模拟 UI 时钟，末击线条使用冻结的特效时钟：暂停不会推进阶段，命中定格保留接触构图。

## 实现与检查

主要实现为 `src/ink/super-director.js`，由正式发动、接触、模拟更新和场景绘制路径驱动。最多维护双方两条演出、32 条诊断事件，以及固定的标题和终结图元。重开清理状态与节点。

`tests/super-director/playable.py` 的 16 项检查覆盖八角色 SA3 的真实启动和末击、资源消耗、落空、被防御、暂停、稳定镜头、减少动态效果、重开和实际界面。画面与报告在 `qa/super-director/`。尚未逐个穷举全部 SA1/SA2/CA 与打断组合，也未做实物设备或长期耐久测试。
