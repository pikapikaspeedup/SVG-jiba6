02 / THE FIRST EDIT

先把不知火舞的一脚，改成你想要的姿势。

选动作 → 拖手脚 → 保存并实战 → 导出游戏
1

选招。进入「动作工坊」，选不知火舞，在搜索中输入「飞翔龙炎阵」。选轻版或中版。顶部显示真实资产路径，右侧有起手、有效、收招帧。

2

改姿势。暂停，拖动时间轴，选择「骨骼」。直接拖手腕或脚踝的圆点，松开后写入当前关键帧。也可改右侧坐标并点击「写入此姿势」。左右箭头逐帧；空格播放 / 暂停。

3

改形体。右侧切「形体」，调整头部、手臂、腿部、胸廓、腰线、髋部，以及骨长与肩髋挂点。形体与骨架是角色级资产，会影响这个人的全部招式，不只当前这一招。

4

改判定与特效。切「判定」添加或拖动方框；选挂点、位置、宽高和生效帧。切「特效」选类型、挂点、时间、颜色、角度与比例。需要自定义攻击范围时，启用自定义判定。攻击框必须放在有效阶段内。

5

进实际战斗。点击「保存并实战」。模型、骨架和当前招式一起保存，随后进入实际练习并发动该招。返回工坊继续调。想改时间长度，修改右侧三段帧数后点「应用时序」，再保存。

6

带走成果。顶部「导出游戏」生成带修改的创作版 HTML；资产中心可导出玩家版。要备份可编辑资产，导出工程 ZIP。

切换到「剪影」先看发力轮廓；用「洋葱皮」看前帧轨迹；0.25× 慢放检查肘膝与收势。特效不能代替动作本身。支持 60 步撤销 / 重做；「恢复此招」只恢复当前招式，不会清空其他角色修改。

选择资产目录
写入全部资产		经你授权的本地 assets/ink 文件夹。之后保存会写入对应角色的模型、骨架和当前动作 JSON。直接维护源码。受浏览器、安全上下文与权限限制。
导出游戏 / 工程 ZIP浏览器下载目录，由你决定存到哪里。离线试玩、转移电脑、归档、发给其他人。
看到橙色“未允许浏览器持久存储”提示时：编辑与对战仍然可用，但当前只是内存工作副本。关闭前必须导出 HTML 或工程 ZIP。不要把浏览器工作副本当作唯一备份。

想和源码同步：进入「资产中心」，授权源码里的 assets/ink 或空文件夹。已有文件用「从目录载入」，新文件夹用「写入全部资产」。读取会校验所有独立 JSON，完整通过才替换当前工程；无权限时使用 ZIP / JSON，不会影响玩游戏。

工程 ZIP 中的 assets/ink/project-overrides.json 可通过工坊「导入」恢复修改。目录跨多个文件写入不是文件系统事务，权限中断或突然断电仍可能导致部分文件已经更新；请保留版本备份。

这三个操作均不会自动上传 GitHub。需要发布到仓库时，把源文件作为正常 Git 改动提交，再重建 dist/。

04 / SOURCE OF TRUTH

动画是数据；SVG 是它被绘制出来的结果。

assets/ink/characters/mai/
├── model.json                 形体、宽度与风格
├── rig.json                   骨长、肩髋与头部挂点
└── moves/
    ├── hishou-ryuuenjin-light.json
    ├── ryuuenbu-light.json
    ├── hissatsu-shinobi-bachi-light.json
    └── state-walk-forward.json …

src/ink/art/mai.js             不知火舞的头发 / 装饰 / 前背衣装
src/ink/design.js              公共脸部视图与原画装配
src/ink/runtime.js             资产 → 同一姿势 / 骨架 → 实战
src/ink/renderer.js            连续 SVG 轮廓、蒙皮与图层

八人分别有原画模块、模型、骨架和动作目录。当前是 690 个独立可编辑条目，其中 522 个战斗条目、168 个待机 / 状态 / 双人编排；轻中重和 OD 分别可编辑，但不冒充 690 套全新独立编舞。

静帧 SVG 只用于美术检查。真正让游戏使用你的动作的是 JSON 关键帧、判定与特效数据，不需要导出几十张 SVG 再逐张贴回游戏。

开发者重建

python tools/build_forge.py

# 完整测试另需 Node.js、Python Playwright 和本地 Chromium：
python tools/check_forge.py

构建只需 Python 3.10+ 标准库，无网络依赖。改 assets/ 或 src/ 后重建。不要把改动只写在生成的 dist/；下次构建会覆盖生成结果。

完整源码包与应用内导出的“工程 ZIP”不同：前者含渲染器、原画、规则、工具和测试；后者是资产工程加可玩成品。要改 JavaScript，引擎开发请使用完整源码包。

06 / TROUBLESHOOTING

遇到问题时，先看这里。

为什么右侧修改后，战斗好像没变化？

点「保存并实战」，确认正在编辑和试招的是同一角色、同一轻 / 中 / 重 / OD 变体。改时序需要先点「应用时序」；自定义攻击框需要选择自定义判定。资产路径与当前招式名称在工坊标题下方。

为什么不能直接写文件夹？

浏览器必须支持目录接口，并通过用户授权；某些本地文件或非安全上下文会禁用它。无需为了继续制作而绕过浏览器限制，直接导出工程 ZIP 或 JSON，手动放入源码路径即可。

玩家版能继续做动作吗？

玩家版只显示选人和对战，是展示入口的简化，不是加密或安全隔离。继续制作请保留创作版或备份 JSON。不要仅保留玩家版就删除源工程。

上传 GitHub 时改哪些文件？

动作改动提交对应 assets/ink/characters/… 文件。改服装发型提交该人的 src/ink/art/…。运行构建脚本后提交新 dist/。新入口是 dist/INK-Street-Fighter-6.html；旧根目录页面被保留作为基线，不会自动换成新版。
