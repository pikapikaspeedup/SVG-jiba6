03 / PRACTICE跟着节奏，自己接招

THE DETAILS

细节不只在“更多粒子”。

出招交接承接上一姿势与速度，在有效帧前回到本招资产。命中定格时，输入缓冲与世界特效一起等待，不让人物停住而火焰先消失。

龙炎舞走扇尖，飞翔龙炎阵走腿焰，忍蜂走肘部冲刺；SA2、SA3 与 CA 补入独立编排。轨迹可以绕到人物身后，花瓣有自己的旋转、阻力与重力。

连段页可选择「清爽 · 低闪动」，减少装饰粒子并关闭额外震动和全屏命中闪光。机器负载较高时，也可关闭粒子与轨迹。

REAL COMBAT, NOT A MOVIE

连段必须由战斗系统判定。

P1：WASD 移动，J K L 拳，U I O 脚。连段页 G 发当前步，R 重置，空格暂停；移动端使用画面上的触摸按钮。6F 是训练提前请求窗口，常规输入缓冲另按 9 个可行动帧计算。
03 / MAKE IT YOURS

在同一份动作上继续雕琢。

打开动作工坊，选不知火舞，再选招式。暂停后拖动时间轴，观察发力前后的折扇与附件；选择「特效」标签，修改对应事件。

字段适合调整什么
扇尖 / 扇柄让焰弧跟着实际折扇走，而不是贴在角色中心
拖尾帧数 / 宽度调整收势留痕的长度和厚度
前方 / 后方让火焰绕过身体，避免一层特效遮住所有动作
花瓣 / 重力 / 卷曲控制花瓣下落、余烬上升及横向摆动

点击「更新特效」后再「保存并实战」。改姿势会立即刷新挂点缓存，不必重新载入招式。

满意后使用「导出游戏」保留当前全部修改，或在资产中心备份 JSON / 完整工程 ZIP。新版不自动读取旧版 v3 浏览器编辑，导入旧动作前先保留两份备份。

注意：动作演武不产生伤害；特效事件也不会替你制造命中。改变动作时序或自定义判定属于你自己的玩法编辑，改完后应重新验证连段。
