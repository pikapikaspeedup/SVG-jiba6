# 疾走踩步出招

MovementStrike 把仍向前移动的 dash/rush 转为站立普通技时的一小段余势变成真实模拟位移。必须实际持续按前且没有按后；松开方向、反向输入及普通站立直接出招保持原规则。没有新增资源条。

仅无现存攻击的地面 dash/rush 可进入，排除蹲姿、空中、抓取、投技、特殊技、已有 travel、连携与取消。prepare 读取旧移动状态及朝向，克隆招式，不写战斗状态。位移预算为速度乘以轻重系数，踢击略小，最多 18 世界单位；前摇最多 5 个行动帧按递减份额消耗。提交方向固定，不因对手换边改向。

代价是轻中攻击额外 2 帧恢复、重攻击额外 3 帧恢复，同时增加 m.recovery 与 m.total。startup、active、伤害、命中框和原有合法取消规则不变。命中确认后的原有合法取消仍然存在，恢复代价主要约束挥空和未取消收势，不应宣传成不可规避的额外硬直。

## 接口与集成顺序

- `prepare(f,m,{forward,backward,cancel,chain,velocity?})`：在状态切换和 vx 清零之前调用。forward/backward 必须来自当前真实输入、按提交朝向解释。velocity 可提供同一模拟步的真实世界水平速度，默认 f.vx，不能用 AI 射程或渲染位置推算。
- `commit(f,G)`：成功建立新 attack 并进入 attack 后调用；绑定该攻击对象，清理前次计划。metadata 为 m.movementStrike。
- `step(f,G,{actionable:true})`：每个可行动整数步、普通 attack.t 推进前调用，返回本步世界 dx。root 使用既有边界和推体规则应用；没有位移权限时不可绕过正式规则直接改根。暂停显式步进可传 actionable，hitstop 始终不推进。
- `clear(f)`：取消、受击或重置时立即清理。step 也会核对绑定攻击、地面状态和捕获状态。

commit 当步不再额外派发位移。重复 actionTick 调用返回 0，渲染不得调用 step。预算按计划份额消耗；碰墙或被对手阻挡没有走出的部分直接丢失，不积攒到后续帧弹出。恢复帧仍保留，不能因阻挡而返还代价。

已接入正式输入、CPU 与动作交接。CPU 只有接近计划允许提前按距离出拳，保留至少 20 帧攻击间隔；临时方向键只释放自己添加的键。前压与制动沿用既有身体阻挡和墙界。

相关短检见 `qa/movement-strike/checkpoint.json`：实际前压/制动、墙侧不积攒、超级技冻结、余势尚余 7.2 时真实受击截断；受击定格内旧计划不再推进。定向 CPU 接管样本自主触发一次前压且没有粘方向键，不代表普遍频率或平衡验收。出招前后脚计划接续，活动帧攻击链误差为 0。未进行新耐久或性能对比。
