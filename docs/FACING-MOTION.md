# 移动与换边

本文记录本轮实现与相关短检。仍有高速冲刺可达残差，旧招式也未全部转换成真实三维模型。

## 朝向所有权

战斗朝向由模拟持有，影响输入解释、判定与正式动作。视觉朝向由 FacingMotion 在行动时钟上采样；视觉身体尚未转完不能推迟战斗换边。暂停与定格不能通过额外 render 推进脚计划或转身状态。

移动族使用中立站姿作为角色标定，避免切换左右行走素材时直接交换脚目标。身体转向与换撑使用不同期限：身体可以先完成转面，两脚仍依次完成已提交的落脚。显式 ownsFeet 表示脚目标所有权；turning 本身不能覆盖已经移交的移动计划。移动或转身结束通过 handoff/adopt 交接实际世界脚点。

## 移动三维与旧动作适配

VisualFrame 的统一空间是 actor-screen，外层不再依靠负宽度或经过零宽度来实现移动转身。移动族从 Anatomy.sourceRig 的角色链长构建三维骨架，胸、髋、头有连续朝向；世界脚目标通过三维两骨求解约束。不可达目标保留 residual；共享视觉下沉最多 24 局部单位，不延长骨段，也不改变战斗根。

厚手和足保留真实厚度投影，薄扇允许侧面变窄。身体与头的表面矩阵和材质方向随转面变化。legacy() 仍提供精确旧姿态适配；旧招式并未全部重建为真实三维。限定的 persistentSurface 分支保持左向表面与厚末端的连续表示，但保留原关节世界 XY；复杂旋转、空中和抓取路径保留兼容表示。

physicalLengths 表示原 source 的段长。旧姿态 joints3D 的深度属于兼容表达，不能据此宣称旧招式都满足真实三维固定骨长。桥接时允许作者投影长度过渡。

## 支撑与攻击接续

FrameBridge 捕获实际 outgoing frame、其世界基准及已经提交的 footPlan。非攻击支撑脚沿原计划独立时钟继续，再以有限收尾交给新动作目标；不能因为快拳的短启动期限而令双脚同时换到另一侧。

攻击链由 contactChains 选定，在原启动期限前交给真实目标；活动帧逐关节必须与无 FrameBridge 的 Runtime.visual 目标一致。快拳使用 deadline 姿态预测，2–3 帧行程采用匀速端点过渡，避免把大部分移动集中于最后一帧。预测是当前 actor-relative 姿态：只有 outgoing 点进行旧世界根到当前根的平移，预测目标随当前根移动。它不模拟未来受击、取消或资源变化，实际期限仍以实时目标为准。

防守前手立即到位，薄扇跟随同一所有权。受击躯干优先响应。所有桥接只改表现，不能延后判定、改变碰撞框或修改伤害。

## 有限证据与待审看范围

`tests/visual-frame/unit.cjs` 覆盖旧适配精确性、八角色朝向采样、移动链长、有限不可达残差、厚末端、薄扇、支撑卸载、攻击链活动帧精确性、采样纯度及根移动预测。它不证明鞋轮廓或整场动作观感正确。

`tests/visual-frame/playable.py` 使用真实输入与招式检查隆和舞的早、中、晚转身接续，报告每肢体二维端点跳变、桥内末端行列式及活动帧逐关节误差。报告绑定具体 HTML 哈希；源码或构建更新后旧报告不能代表新版。局部二维距离不是屏幕像素；需乘角色缩放后才可比较舞台像素。

仍需重点观察快拳大角度换边的行程、宽站姿脚计划、踢腿时支撑交接、侧面足部轮廓及复杂旧动作兼容切换。短检查不能替代完整动作覆盖或耐久测试。

## 可玩行为与当前证据

输入使用即时 `intentDir`；已经提交的攻击保持 `f.dir`，新招被接受时再切换正式朝向。角色身体转面不锁住输入。普通跳跃的顶点约为 169 个世界单位，旧身体阻挡高度 170 使普通跳无法跨身；本轮将该阻挡的垂直重叠门槛调整为 110。地面身体阻挡宽度、伤害和原命中判定保持，真实按键下隆与舞均已完成跳过对手、落地换向与立即接受轻拳。

当前移动计划一旦取得所有权，FrameBridge 不再覆盖它；仅出拳等没有实时移动脚计划的动作延续捕获的落脚。停车卸载开始后，可达区间轻微变化不会把 blend 重置为 1。嘉米原停车场景的最大交接跳点从 41.643 降到 11.308，支撑残差为 0；墙边场景的支撑残差为 0、摆脚约 3.019。隆高速冲刺后脚仍有最大约 41.766 的目标可达残差，后续应改进抢步与后脚释放时机。

转身接续短检覆盖隆/舞早、中、晚时机的轻拳、重脚、防御与受击，共 24 场；活动帧关键链与真实目标误差为 0，厚末端没有矩阵过零。隆最早轻拳的启动端点行程由末帧集中约 103.26 改为每步约 72.04 局部单位；有限的三帧启动仍需要快速运动，不宣称任意短启动都能慢速转身。

证据索引为 `qa/facing-motion/checkpoint.json`。各报告保留原成品哈希：停车生命周期修正使用嘉米独立场景复测，最后的取消换向捕获修正另用同侧与传送跨侧两例真实命中确认取消检查；未把旧矩阵报告改标成最终版本。最终生产脚本语法与 707 份原资产检查通过。本轮没有完整耐久或同条件性能对比。

已提交攻击被反向新招取消时，先保存原朝向的完整模拟快照，再提交新朝向；旧帧与新帧分别用各自世界基准计算。两例 sMP 命中确认接波动拳的第 0 帧四链误差为 0，活动帧关键链误差为 0。跨侧案例使用显式传送夹具，不能当作自然跳跃取消覆盖。
