# 共享防守身体

第十六轮把八角色站走、刹步、冲刺、下蹲、高低护架、招架及地面无攻击恢复接入同一个规则身体。`RulePose` 是入口，`RuleBody` 负责有限计划与纯采样，`DefenseBody` 解固定三维骨长；最终 SVG 与 20 个分部受击代理消费同一模型。原生 24 普通技继续由 `StrikeModel` 拥有。

## 实际玩法

输入资格立即按既有方向、高低防、硬直判断。完整下蹲 4 行动帧、起身 5 帧；护臂高低切换 2 帧，抬护/招架 2 帧、收护 3 帧，均不新增操作锁。反向输入先从当前值与速度做至多 .75 帧刹车，再五次曲线到目标；保证有界 C1，不声称全过程 C2。按下方向不立即把头部传送到最低点，松开下方向也不借低姿保留低防资格。

护臂属于真实受击体积，前探会增加暴露；格挡仍可发生于任意有效身体接触，不要求一定打在手臂。投技对新防守身体读取同源头、躯干、腿代理，排除新添的臂段，避免伸手额外扩大抓取范围。舞扇只用于姿态辨认，没有新增扇纸防御或无敌面积。

八人采用独立身体、手型、站位和负载数据。高低护的后腕和后肘经过实际左右渲染调优，使头侧后手可读；这部分偏离 Pro 初始极坐标建议，直接改变三维手位及其代理，不伪改渲染深度。蛛俐的静止提脚通过既有脚计划在进入防守时有限落下，落地前不伪造承重。

## 统一支撑与承压

脚目标优先持续 Facing 换撑，其次现有 Locomotion 步态，再静止锚。站蹲/高低防只改身体，不重建双脚锚。仅已落地、实际承重腿请求最多 12 native 的公共骨盆下沉；水平不可达保留残差，不能拉长骨头。移动、转身接攻击仍可能有短时支撑残差。

格挡冲量分为世界二维前臂与躯干通道，临界阻尼频率 .55/.32 每行动帧。冲量按招式 level、末段及招架结果计算，同批求和后限幅；不读取装饰能量或 Kinetic 增益。满载骨盆水平/侧倾/垂向预算分别为 2 native/2 度/2 native，前腕退让为角色化 5–8 native，后腕为其 .35。原 root push、YIELD/ESCAPE 位移和费用不变。

近战共同几何先完成，推箱后再冻结弹体阶段几何。承压只在全部接触之后提交速度，因此当前拍不会因遍历顺序缩回手臂。弹体后续候选遇到 hit/离地/捕获等 owner 变化即放弃旧几何提议，弹体本身继续原更新。暂停与 hitstop 不推进承压。

## 交接和兼容

防守到原生攻击捕获纯规则身体，前摇最多 3 帧的载体差量同时用于显示和碰撞，活动段参数保持。攻击返回防守承接实际脚点和身体，再趋向当前输入目标。地面兼容受击使用明确的 canonical return seed，显示受击收敛到该目标；退出后规则身体从同一目标开始，不把含装饰反应的画面烘焙为规则初值。

模型、骨架或本族覆盖的 idle/walk/dash/rush/land/crouch/block/parry 资产任一编辑后，整个防守族回兼容。编辑仍可保留未经修改的原生攻击，入口直接采保存的 clip 和 legacy combat 求解，不经表现开关或显示桥。编辑、瞬移、重置清理计划并断 epoch。

同 owner、同朝向的防守换态使用八分帧曲线扫掠。当前版本跨朝向符号、原生攻击与防守 owner 切换，以及原生/旧受击拓扑交界仍明确视为缺少连续覆盖；不强配 20 与 4 个盒，也不据此制造 cleanMiss。新建身体仍为二维分部 AABB 近似，具有空角误差；2.5D 厚度不是实体网格碰撞。

## 检查范围

`qa/shared-defense/checkpoint.json` 绑定 S/H/L 三张正式合照与具体构建；`fight.json` 记录少量真实高线、低扫、多拍格挡交锋。载体入口、编辑开关及跨身/受击链有明确独立构建记录，不把早期数据当作最后版本全部重测。另执行解析承压有界检查、原 707 资产和生产语法检查。没有新增回放、性能或耐久结论。
