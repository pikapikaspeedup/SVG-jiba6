# FLOW 09：稳镜与流畅动作

## 打开与设置

直接打开 `dist/INK-Street-Fighter-6.html`（创作版）或 `dist/INK-Street-Fighter-6-Player.html`（玩家版）。两者均为自包含文件，不依赖在线脚本。首页与实战顶部都有「稳镜与流畅」入口。个人设置优先保存在本浏览器；浏览器限制本地存储时，导出独立 HTML 才能携带设置。

默认：稳定舞台 / 连贯节奏 / 1× / 完整特效。默认不是降低画质。稳定舞台的相机矩阵恒等，出招、命中、超级必杀均不会挪动或缩放背景。柔和跟随明确允许相机随角色根位置缓慢移动，但不响应肢体伸展和命中震屏。原「特写」按钮是独立的主动选择，会覆盖普通镜头模式；重新选择稳定舞台即可退出特写。

连贯节奏减少反复命中定格，会改变一条连段消耗的现实时间，但不修改招式的动作帧数或取消规则。重心节奏保留 v8 的停顿；v6 原始停顿也可选择。感觉节奏太密集时可以单独选择 0.85×，不会暗中自动调速。

诊断面板不暂停实战：显示最近最多 600 个实际回调、回调间隔 P95、引擎 CPU P95、超过 25 ms 的回调次数及有意命中定格步数。P95 为该窗口 95% 样本不超过的数值。浏览器与系统调度、页面布局绘制也会影响回调间隔；CPU 项仅测游戏主循环中的同步工作，不是整台机器的 CPU 使用率。打开面板本身也有界面开销。导出 JSON 包含样本与设置，不包含输入录像或硬件认证。

## 引擎改造

### 1. 模拟端拥有时间与冻结

`presentation-clock.js` 保存前后模拟状态，`game.js` 根据相同 alpha 求值，不再以「这一招是否第一次画」决定能否插值。`bindControl()` 将对 `G.paused` 的直接写入统一成暂停边界，进入暂停时记录冻结令牌；真实主循环的 `boundary()` 处理恢复、场景与可见性边界。冻结结束时不会因为此前少画了一帧而反向跳姿。

基础待机、动作层、非攻击附件读取同一角色时间。菜单预览则明确使用预览时钟。确定性合同指相同模拟状态及给定时间的姿态输出，不代表 SVG 渲染不会更新缓存、节点或展示用字段。

### 2. 按需编译与共享几何

`articulation.js` 仍按 0.25 个动作帧（240 Hz）求解角度，`secondary-dynamics.js` 仍按 0.5 帧（120 Hz）积分弹簧。缓存按请求帧向前扩展，不在第一次出招时阻塞计算整段 SA3。顺序与原完整烘焙一致，反向查看已构建部分不重新积分；编辑修订会使旧缓存失效。

连续皮肤的中心线一次采样，共享给主轮廓、光与阴影。没有可见带的躯干侧面不重复变形；隐藏着色层不生成无用路径。坐标串行化减少临时数组。HUD 仅在值真正变化时写文本和属性。

骨架仍完整采样，没有增大关节步长、跳过人物帧或以隐藏部件提升数字。旧版热路径调查中未发现同步 `getBBox/getCTM/getBoundingClientRect` 读取，因此不能把这些改善包装成「修复强制回流」；实际优化是求值、字符串构造和冗余节点写入。

### 3. 世界挂点与镜头解耦

`effects.js` 在模拟时记录动作实际求出的世界挂点，每条挂点历史最多 96 个半帧样本。渲染拖尾通过二分查找读取、插值，再转回当前渲染局部空间，不用当前身体重算整段过去。原有世界粒子与带状轨迹生命周期保留。

编辑器没有实战历史，仍用可重建的采样路径；旧历史超出窗口也有受限回退。特效长时间关闭后开启，只补有限窗口，不重放整场。采样共享机制和默认完整粒子密度参与性能基准。

`viewport.js` 的稳定模式输出精确恒等矩阵。跟随模式只读取插值根位置，并有死区、最大 dt 与指数平滑，冻结时保持相机；不再使用头、腕、踝的瞬时包围盒控制镜头。

## 兼容与测试

正式入口仍为 `SVG_FIGHTER`、`INKForge`；690 份动作、16 份模型/骨架与路线库共 707 个原始资产文件逐字节保留。共享命中停顿配置增添 `fluid`，原 `weighted` 和 `legacy` 未删改。个人旧工程请备份后选择性导入；新版本使用 `ink-flow-sf6-v9` 独立空间。

```sh
python tools/build_forge.py
python tools/check_flow9.py
# 浏览器测试需要 Python Playwright 与可执行 Chromium；构建本身只需 Python 标准库。
python tests/flow9/contracts.py
python tests/flow9/rhythm-matrix.py
python tests/flow9/final-regressions.py
python tests/flow9/ui.py
python tests/flow9/portability.py
python tests/flow9/benchmark.py --baseline --seconds 25 --label local-old
python tests/flow9/benchmark.py --seconds 25 --label local-new
python tests/flow9/endurance.py --seconds 1500
python tools/check_flow9.py --evidence --require-soak
```

性能基准必须独立顺序运行，不能与压力测试并行。继承的旧 QA 保留用于追溯，只有 `qa/flow9` 中明确绑定当前 HTML SHA-256 的记录才是这轮执行证据。具体结果、初期失败与验证限制见 `TEST-REPORT-FLOW9.md`。

## 已知限制

仍然是 2.5D SVG，换边镜像、双人投技等未在本轮重写。减少渲染 CPU 不保证所有电脑、手机或内嵌浏览器都流畅。手机测试为模拟视口和触摸，不是真机认证。首跳到动作末尾仍需构建前缀；这是编辑器随机跳帧的工作，不应当与首次正常出招开销混为一谈。稳定镜头不等于关闭人物受击位移、火焰、地面冲击或有意命中定格。
