# 下一阶段：身体参与对抗

目标：将身体支撑、接触、受击和战术选择贯通，让同一招在不同距离和接近方向下产生可读、可利用的差异。保持正式模拟对根位移、判定和帧数据的所有权。

## 工作安排

用户授权两个子 Agent。主 Agent 负责主循环、运行时、表现事件与可玩入口整合；子 Agent 一负责支撑发力与骨架约束；子 Agent 二负责方向性接触、受击和击退规则。源码各自分工，不并发改写共享主文件；统一构建后检查实际拳脚和交锋。

| 大交付 | 范围 | 状态 |
| --- | --- | --- |
| 身体与接触 | 隆/嘉米：支撑脚、起停转向、肩胯发力、接触方向与距离、有界击退/防御退让、统一接触反馈 | 已交付 |
| 攻防与连携 | 命中/防御分支、距离收益、付费脱压；CPU 使用同样的规则和反应限制 | 已交付 |
| 八角色与表现统一 | 推广角色身体风格，统一特效/音效/画面可读性，处理多段和复杂场面 | 已交付 |

第一阶段不扩大原命中框，不改变招式伤害、硬直、启动/活动帧；新接触规则只覆盖样板角色的地面单段非击飞/非击倒普通技，其余继承现有规则。脚锚必须在实际模拟步建立，绘制不可决定下一次接触结果；脚部约束要遵守动作的支撑/攻击脚所有权。

## 交付标准

先让隆与嘉米在普通进退、急停、出拳和受击时有清楚的身体差异。以直接对练、角色姿态/脚部检查和必要的规则回归确认；不把工具、报告或小修单独计作大升级。长期平衡与实物设备不冒充已完成。

## 本轮实际交付与后续顺序

第一交付已整合：隆/嘉米的承重与急停转向、普通技肩胯发力、受击退步释放、共用接触描述的身体/局部特效/音色，以及有限的命中和防御退让。支撑脚修正在视觉桥之后生效；新招的攻击腿优先，手臂和原骨长保留。普通对战也预先分类双方接触，使第一方结算不会抹掉另一方的同时命中。

距离规则使用两角色各 10 个普通技的显式根距带，校准来自实际活动帧战斗盒，旧 AI 射程估计不参与。命中推力乘数 0.82–1.22，防御 0.86–1.16；典型重拳总退距差异只是几个世界单位。本轮主要收益是身体与接触的可读性，并非已经完成新的空间攻防系统。原伤害、硬直、活动帧和 707 份资产保留。

第二、三阶段现已整合。第二击命中后可免费收尾或花 1 格斗气追距，被防后可花 1.5 格再压；各角色使用不同的招式和逐帧位移预算。付费分支终止当前普通连携，再压留下真实 4 帧行动空隙。防守方可花 0.5 格退让、1.5 格脱压，或使用既有 2 格反击；这些选择都有空间、恢复和资源代价。CPU 走同一资源与出招入口，使用已有确认延迟，八组实战样本中实际用出了追距、再压与防守选择。详见 `docs/PRESSURE-FLOW.md`。

身体支撑与方向接触推广到八角色，各自具有支撑、发力、护架与受击风格。八角色 80 个普通技距离带来自真实几何校准；特殊、波、多段和投技也生成统一表现描述，但不因此修改原有推力。身体、局部冲击、音色与舞台照明共享接触位置及方向，多段构图保留每名受击角色最新两层。八种身体语言、材质核心形状、接触音色与范围见 `docs/EIGHT-FIGHTERS.md`。第二、三阶段没有追加 Pro 咨询。
