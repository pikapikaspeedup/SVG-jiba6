# 八角色连续体积造型

本轮修改 `src/ink/skin-geometry.js`、`src/ink/renderer.js`、`src/ink/design.js`。不新增运行模块，不修改 707 份原始动作/模型/骨架/路线资产，也不移动战斗关节或扩展命中框。

## 实际算法

连续肢体仍来自同一条三关节中心线：上段 7 个采样、圆滑关节 5 个采样、下段 6 个采样，共 18 个截面。上段半径由端点插值叠加肌腹曲线；下段使用偏向近端的肌腹峰，保留腕踝收束。八角色分别指定臂、腿的上段峰、下段峰和衣料膨起系数。

弯曲量由两骨方向夹角计算。固定的关节衰减曲线使内侧最多收缩约 16%，外侧按角色衣料系数有限膨起；左右法线轮廓由闭合三次曲线连接。固定衰减表只创建一次。前景手臂裁切罩覆盖新肌腹外形，但仍只裁切已经存在的表面，不创造新几何。

衣料和皮肤共用一张连续底色面，替代上下骨段分别填色造成的接缝。原有衣袖、靴口、护腕与服饰纹样继续保留。连续侧阴影与亮面沿中心线变化；关节压痕改为随弯曲增强的短内侧曲线，不再横切整条肢体。躯干新增三块角色专属体积面，经过现有三权重躯干蒙皮。

## 角色区分

| 角色 | 本轮具体区别 |
| --- | --- |
| 隆 | 较明显上臂峰，宽松道服腿面，胸腹肌理分面 |
| 肯 | 中等臂部肌腹、较大的衣料关节膨起，夹克襟面与长裤连续分面 |
| 春丽 | 八角色中较突出的上腿体积，收束膝踝，旗袍腰身与胸部平面 |
| 嘉米 | 上腿与小腿肌腹均清晰，裸露皮肤连续体积与原有迷彩保留 |
| 卢克 | 最明显的前臂肌腹峰，短裤与裸小腿区分，背心胸廓体积 |
| 蛛俐 | 较细臂部与修长腿部，保留左右裤腿色差和粉色线条 |
| 不知火舞 | 柔和上腿/小腿曲线与收束手腕，红白衣襟和腰腹分面 |
| 八神 | 袖口细长、关节处衣料膨起，深色外套与裤面连续体积 |

这些参数是表现轮廓，不是角色碰撞体积或官方人体比例。

## 所有权与边界

`SkinGeometry.sampled/sweep/band` 为只读几何函数，输入关节不变。Renderer 只更新固定 SVG 节点的属性；角色资源挂载时新增少量固定躯干路径，逐帧不新增节点。蒙皮不反向写入骨架、根运动、资源或判定。暂停与重复相同状态渲染保持一致。

已检查 96 组几何边界：八角色、臂腿、0/45/90/135/175/180 度；路径无 NaN/Infinity、半径正值、输入关节不变。八角色各执行重拳与重脚共 130 个动作步，检查路径有限、战斗状态与几何只读、同态 SVG 确定性和重复渲染节点数稳定。证据在 `qa/model-upgrade/geometry.json`、`motion.json`，后者绑定实际构建哈希。
