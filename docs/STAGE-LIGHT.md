# STAGE LIGHT：战场光影与人物层次

第七轮引入统一的 SVG 场景照明：环境光、人物受光、脚底接触影和战斗局部光一起工作。默认开启；“体验格斗升级”中可切换战场光影和三张场景，不需要重开对局。

## 表现

- 雨夜街角使用青蓝主光和紫色补光；庭院使用暖色主光与偏冷补光；天台的月光方向与画面中的月亮位置一致。
- 角色使用当前真实原画的 alpha 蒙版接收光照，衣服、皮肤、头发轮廓仍清楚。最多接受两个局部光源；亮度受限，不靠全屏白闪表示强度。
- 投射物、发波蓄力、真实命中和对冲提供最多六个场景光源，同时影响背景附近、地面和人物。光的衰减使用战斗特效时钟，命中定格和暂停不会继续闪动。
- 地面投影随高度变宽、变淡；双脚的接触影读取求解后的足端位置，离地即淡出。倒地使用较宽的身体投影。
- 背景与相机保持稳定，环境染色不改变位置或战斗速度。普通接触不改变场景整体曝光。

## 集成

`src/ink/stage-light.js` 统一管理环境和局部光源，正式角色渲染调用它并传入已经求解的骨架，避免重复解算。动态轮廓使用 SVG `<use>` 和 alpha 蒙版，没有复制整套原画 DOM，也不把光照写回战斗状态。场景有六组固定光场；角色各有一组环境渐变、两个局部光和两个足端影。

重开和更换角色清理光照节点；工坊使渲染器失效时也清理旧蒙版。关闭开关后恢复原有投影尺寸与显示。场景选择沿用原场景资源，未重画三张背景；这是风格化二维照明，不是三维法线、遮挡或光线追踪系统。

## 检查

`tests/stage-light/playable.py` 覆盖三场景、真实接触光源、轮廓蒙版、编辑后重建、暂停纯绘制、稳定镜头、跳跃投影及关闭恢复。代表画面和报告在 `qa/stage-light/`。

`tests/stage-light/frame-cost.py` 是短时同步 CPU 采样，开启后的两组均值约 1.00–1.02 ms、p95 约 1.6–1.7 ms；不代表 GPU 合成、显示帧率或低端设备表现。该采样早于月光位置校准，以报告中的构建哈希为准。没有进行实物移动设备与长期耐久验收。
