# KINETIC 格斗表现升级

这是十轮目标中的第二轮完整升级，先前 FLOW11 重演基础不计入大迭代。本轮不调用 Pro，设计与实现由 Codex 完成。

## 玩家可感知的变化

- 动作：起手加载重心，肩胯在出击时反向释放，收势恢复；受击按实际接触位置分为头、躯干、腿、防御四种响应，保留连续打击的残余冲量。攻击者具有接触回弹。落地按速度产生承重压缩和地面波纹。
- 动作特效：普通拳脚按真实肢端路径及速度生成有宽度变化的轨迹，特效与模拟同步，在命中停顿中保持；多段中间击与终结击区分。
- 画面：接触点的局部照明、方向冲击线、分层核心/波纹；防御、招架和落地有各自构图，不移动稳定背景。效果使用最多十二个保留节点组及三十二条事件。
- 打击感：流畅模式轻拳定格由 4 改为 3 帧、重拳由 7 改为 9 帧；确反额外 2 帧、反击额外 1 帧；中间连击不增加额外停顿。关闭新模式恢复原有定格计算。伤害、移动速度和内置动作资产没有改动。

首页“体验格斗升级”进入练习，支持八角色、轻重拳脚、各角色必杀、真实跳跃、站立/防御/CPU 木桩，以及同场新旧切换。界面按钮使用正式输入入口，不能绕过硬直、取消条件或资源。

## 实现边界

`src/ink/kinetic.js` 从已提交的真实接触生成身体与画面响应，正式动作采样在最终视觉层应用修正并继承 Articulation 关节上下文；战斗根位置与碰撞仍由原模拟控制。game.js 将真实接触位置、方向、确反/反击、末击信息传入。姿态按模拟角色时钟读取，不按绘制次数累积。完整的惯性连招交接、空中机动、投射物体系及全场动态照明属于后续大迭代，未将其宣称为本轮成果。

## 已执行检查

`tests/kinetic/playable.py`：11 项通过，包括真实重拳命中、分层反馈、节奏差异、同场关闭、新特效有界、八角色 CPU 运行、角色选择/跳跃落地、390 宽度布局和无浏览器异常。截图及绑定成品哈希见 `qa/kinetic/`。这是直接可玩检查，不是长期耐久或实物手柄验收。

`tests/kinetic/frame-cost.py`：独立顺序运行，不与其他负载并行。舞/八神 CPU 情境，预热 120 步后采样 300 次同步模拟和绘制。新模式两次均值约 0.99–1.01 ms，p95 约 1.6–1.7 ms，保留节点组为 12。此为无头浏览器同步 CPU 开销；节奏不同会改变工作量，不能据此宣称新模式更快，也不代表显示帧率或 GPU/真机性能。
