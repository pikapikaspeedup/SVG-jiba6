# STRIKE FEEL：部位传递与接触音色

第八轮将受击部位、身体回弹和音效统一到真实接触事件。默认开启；“体验格斗升级”中的 STRIKE FEEL 面板可比较轻拳、重拳、下段和新旧表现，音效仍需玩家主动开启。

## 身体反应

头部分类读取本次求解的头部位置，低段采用腿部反应，其余通过接触点与骨盆区分。防御、招架使用独立的支撑反应。

- 头部：头颈先转，胸肩滞后跟进。
- 躯干：胸腹压缩，肩胯错开，重心随后回弹。
- 腿部：骨盆扭转、屈膝、重心下沉，另一侧维持支撑。
- 防御：手臂吸收、肩部退让；招架的退让较小。

受击冲量采用有界衰减振荡与延迟传递。新命中继承 KINETIC 的残余能量处理；反击、确反和重击使用原有接触强度。动作采样时间冻结时，回弹也冻结，结束后回到原动作。保留解算元数据和连携交接；不改命中框、伤害或硬直。

## 声音

轻/重、头/身/腿、防御、招架和投落分别使用音高、噪声频段、持续时间不同的合成音层。强击增加短促的高频起音，中间连击降低强度，超级技末击与中间击区分。声音根据实际接触位置进行有界左右声像定位。

音效由 `combatEvent` 触发一次，绘制不发声。旧命中音效在新模式中停止重复播放，投落也避免同时叠加两次落地重音；抓取和释放的动作音仍保留。复用既有六组并发声音、压缩、限幅和静音管理，新增声像节点随音源释放。

## 实现与证据

`src/ink/strike-feel.js` 提供部位分类、身体响应和音色配置；`kinetic.js` 使用响应，`game.js` 将接触与 Web Audio 联动。`forge/strike-feel.js` 提供直接试打入口。

`tests/strike-feel/playable.py` 检查真实轻重/下段/防御/招架、部位差异、回弹结束、音色和声像、中间击收敛、伤害一致、绘制不重发音效，以及真实按钮启动的 Web Audio 音源和静音。画面和报告在 `qa/strike-feel/`。继承连携检查仍通过。

这些证据确认调度和规则，不代替耳机/扬声器主观试听、硬件音画延迟测量或全角色逐招美术评审。
