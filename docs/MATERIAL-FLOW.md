# MATERIAL FLOW：材质驱动的动作特效

第五轮把角色特效从固定轨迹形状升级为保留释放时刻、速度和材质运动的轨迹。默认开启；首页“体验格斗升级”内可切换“材质运动”，并直接试当前角色的近身必杀。适用于正式对局及动作预览，不修改伤害与判定。

## 可见变化

| 角色 | 运动与轮廓 |
| --- | --- |
| 隆 | 压缩气劲：分层波带与明亮中心线 |
| 肯 | 烈焰：速度继承、浮升、起伏边缘与冷却火星 |
| 春丽 | 气带：细长多层弯曲流线 |
| 嘉米 | 切风：窄截面、高阻力、快速碎片 |
| 卢克 | 气压：断续脉冲与延伸冲击碎片 |
| 蛛俐 | 涡流：相位错开的扭转轨迹和旋转弧片 |
| 不知火舞 | 扇面展开；火焰事件使用卷升火流，其他事件保留花瓣碎片 |
| 八神庵 | 三路爪痕、苍炎浮升与切割弧片 |

轨迹截面随动作速度变化，尾端按释放时间向外输运、卷曲和上升。取消或收招后，已释放的世界轨迹继续短暂消散，不粘回当前拳脚。近身特效由同一几何内核处理，保留柱、环和冲击等独立事件形态。普通拳脚仍以简洁的物理轨迹为主。

真实特殊技接触时，命中碎片沿攻击方向释放，被防御则产生反向散流。多段中间击采用较少碎片，避免连续接触淹没人物。投射物主体及相消规则留给下一轮。

## 实现边界

`src/ink/material-flow.js` 提供材质配置、解析轨迹几何、粒子运动和接触释放；复用 `RibbonPool`、`FXEmitter`、`Effects` 和现有世界粒子池。没有新增无界粒子系统，不使用 Canvas 或滤镜。世界轨迹仍最多 64 条、每条最多 64 个采样点；世界粒子池仍为 320 个槽位。显示阶段只采样，不产生新粒子或改变战斗状态。

关闭材质运动后，轨迹恢复既有绘制方式；已经释放的粒子按出生时的属性完成生命周期。降低动态效果时不启用新的贴身材质几何。旧动作资产和用户工程不迁移。

## 本轮证据

`tests/material/playable.py` 覆盖八位角色真实必杀、颜色之外的几何差异、接触方向、暂停绘制、开关、面板布局和战斗结果一致性；报告和代表招式截图在 `qa/material/`。

`tests/material/frame-cost.py` 是顺序运行的短时同步 CPU 采样，打开材质的两组均值约 0.89–0.92 ms、p95 约 1.5 ms。不能据此声称 GPU 帧率、真机表现或性能提升；未做全招式逐帧美术验收和长期耐久测试。
