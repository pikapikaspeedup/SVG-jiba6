COMMAND LIST / 招式实验室

招式按实际可执行的动作列出。方向始终相对面朝方向，P 为拳，K 为脚。

HOW TO FIGHT / 操作指南

先在练习模式开启无限能量，再练搓招与取消。

01 / 经典六键与搓招

1P：WASD 方向；J / K / L 轻中重拳，U / I / O 轻中重脚。后退防御，↙ 蹲防。向前 / 向后连点两次进行冲刺 / 后撤。V 或 LP＋LK 为投技。

波动输入：按 S，再同时 S+D，再松 S 留 D，接 J。即 ↓↘→+P（236P）。升龙：→↓↘+P（623P）。两次波动：↓↘→↓↘→+P（236236P）。左右换边后会自动镜像。

支持斜方向、输入缓冲、蓄力 [←]→ / [↓]↑、同类双键 OD、轻中重强度。蓄力需持续约 0.65 秒；236 / 214 需在约 0.65 秒内完成。摇杆滑动支持斜方向。

02 / 斗气不是一层绿光

Q / MP＋MK：斗气招架。起始消耗 0.5 格，按住持续消耗；开头 2 帧成功为完美招架，恢复能量并产生慢镜头。投技可以击败招架。

招架中前前（Q＋DD）或 F：斗气迸发，总计 1 格。可取消普通技命中或被防御后，前前 / F：取消迸发，消耗 3 格。迸发后的首次普通技增加 4 帧硬直，真实支持接续连段。

E / HP＋HK：斗气冲击，1 格、两次霸体，第三击破甲。防御硬直中向前＋E：斗气反击，2 格。必杀输入加同类双键：OD，2 格。疲劳时无法使用斗气，防御必杀会削血，角落受冲击可被眩晕。

03 / 派生、超级必杀、辅助

每人有轻、中、重、OD 必杀变体，以及各自的架势与命中派生。↓↓＋任意脚进入本作扩展架势，再接六个攻击键之一；可追击的派生命中或被防御后，再按招式表中的 HP / HK 接二段追击。招式表能查看每个派生的判定与效果。

SA1：236236＋P；SA2：214214＋P；SA3：236236＋K。消耗 1 / 2 / 3 格超必杀能量，低于 25% 生命时 SA3 自动升级 CA。正式对局从零积攒超级能量；练习模式可使用无限能量。

「辅助」保留经典输入，同时开放 Z / X / C / B 四种必杀，1 / 2 / 3 级超必杀；触屏“必杀 / SA”快捷按钮同样仅辅助模式启用。快捷操作仍需能量并遵守硬直。F 为通用迸发合键，不跳过费用。

04 / 练习、本地双人与手柄

练习可选择木桩、全防、蹲防或 CPU；切换无限能量、自动回血与判定框。暂停时 N 逐帧，R 重置。招式表中的“练习此招”会建立必要状态并演示，演示不是在线对战。

2P：方向键；小键盘 1 / 2 / 3 为拳，4 / 5 / 6 为脚；0 招架、小数点冲击、+ 投技、Enter 迸发。请开启 Num Lock。部分键盘有多键冲突，可使用合键替代。

标准手柄：左摇杆或十字键移动；X / Y / RB 对应轻中重拳，A / B / RT 对应轻中重脚；LB 招架，LT 冲击，View / Select 投技，L3 迸发，Start 暂停。辅助模式按住 R3，再用 X / Y / A / B 释放四种必杀，LB / RB / RT 释放 SA1 / 2 / 3。第二个手柄可在本地双人中控制 2P。

H 招式表，P / Esc 暂停。浏览器失焦自动暂停以避免卡键；选人可自由搭配镜像战。音效需点击“音效”开启。本作采用独立帧数据与扩展派生，不宣称官方版本数值或完全等同原版。
