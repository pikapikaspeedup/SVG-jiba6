# INK FLOW 08 · 动作响应与实战姿态回放

基于用户提供的 FLOW 07，继续修复实际运行中的动作与特效问题。本版没有新增伤害、判定、硬直或免费资源，也没有再新增一批预制连段：707 份既有动作／模型／骨架／连段 JSON 与 v7 逐字节一致，其中包含 690 份动作和 22 条路线。新代码处理的是同一招式在显示帧之间如何运动、状态变化时怎样接续，以及场景特效如何共享暂停和冻结。

## 打开与体验

解压后打开 `OPEN-ME.html`，或直接打开 `dist/INK-Street-Fighter-6.html`。玩家版为 `dist/INK-Street-Fighter-6-Player.html`。文件名中的 6 是延续的构建路径，内嵌版本为 `8.0.0-ink-response`。两份 HTML 均内嵌运行脚本、SVG 和资产，不需要 npm、联网字体或外部素材服务。

先从首页进入 **「打开实战动作回放」**。选择「跳跃 → 落地 → 缓冲」，点击「运行并记录」，将时间轴拖到约 48–60F；再选择「真实扫腿 → 倒地 → 起身」，看接触事件、倒地和起身。场景按钮会重新建立训练对战，并通过真实输入、真实命中运行；不是仅仅摆好几张姿势。

普通对战中，点击 **「录制实战姿态」**，操作自己的招式，再点一次停止并查看。最多保留最近 **600 个模拟步**，包括命中定格；1× 下名义上约 10 秒。时间轴支持小数帧、倒拖、±1F、事件书签和 0.25×／0.5×／1× 回放。方向键逐帧，Shift＋方向键移动十帧，Esc 关闭并恢复打开前的暂停状态；生成了新的训练场景时则保持暂停，避免自动接着打。

导出的是已解算的姿态 JSON，包含两位角色、骨架、装扮模型、关节角、发辫／衣带等附件姿态与事件。对方可在本版的同一入口导入查看。`qa/flow8/sample-knockdown-replay.json` 是实际扫腿后的示例。**这不是输入重演、录像或回滚存档；不回放音频、粒子和判定框，也不重新计算伤害。**

## 这轮变化

**运动采样。** v7 的攻击时间已有插值，但行走周期、跳跃速度、落地时间和部分附件仍在整步切换。现在在模拟侧保存上一完整状态，让身体、附件及投射物在同一小数帧位置取样。不是插值完后再去改战斗数据。跨状态、命中定格、暂停和双人投技的特殊约束不会被强行混为普通移动。

**状态交接。** 普通收招之外，接入行走／停步、起跳、落地、受击、防御、倒地与起身。交接来源是当时真实求值的姿势与速度，不读取“上一次恰好绘制的姿势”。受击的躯干反馈立即发生，手臂和武器短时接续，避免为追求平滑而让中招显得迟钝。规则换边依然镜像；没有用缩放穿过零来假装转身。

**落地反馈。** 着地的竖直速度产生有界缓冲和附件响应，普通身体压缩最多 7 个角色局部单位、附件信号最多 22 个可行动作帧。发辫、衣带采用可随机访问的阻尼响应。招式开始时交接这些表现，不增加落地硬直，不把回弹带进下一招攻击判定。

**场景特效。** 倒地地面冲击纳入统一池和开关；残影来自真实解算身体与附件，而非不再更新的旧部件 DOM；最多保留六个复用残影渲染器。镜头震动按世界特效时钟采样，暂停和命中停顿不会仍按现实时间晃动。清爽模式不生成残影，关闭特效会立即隐藏已有残影；作为攻击实体的投射物本体不会因关闭装饰特效而消失。

## 保留的工具与节奏

v7 的「自由连段与节奏」、G 键单步练习、有限取消规则、舞的六条拓展路线、48 步编排、保存副本和独立 HTML 导出均保留。希望从容观察时仍可选择 **重心节奏＋0.85×**，但 v8 没有悄悄降低默认速度；默认 1×，逻辑仍为 60 Hz。没有标定官方游戏的真实招式节奏，不声称与官方逐帧等价。回放速度和对战速度是两个不同控制。

回放右侧的三个开关影响后续实际模拟，不会重算已录数据。需要 A/B 比较时，先改设置，再重新运行同一场景。独立 HTML 导出携带这些设置；导出的 JSON 则保存已经得到的姿态。

## 保存、迁移与离线

v8 使用独立的 `ink-flow-sf6-v8` 存储，不自动覆盖 v7。旧工程先导出备份。既有动作、模型、骨架和连段格式继续兼容，直接导入即可；导入旧资产仍会以用户文件替换同名资产。姿态回放单独通过「导入回放」读取，不要拿它当动作工程导入。

浏览器限制本地存储时，界面会提示暂存，此时请在关闭前导出工程／HTML／回放。玩家版隐藏编辑入口，不是安全权限隔离。本次环境阻止 `file://`，测试使用完整 HTML 字节独立打开；已实际执行浏览器文件上传和下载，但未替用户验证原生目录授权。
